AI Page Translator — Options

Bring your own API key, or run a local model with Ollama. Nothing is sent to any backend; keys stay in this browser only.

AI Provider

Glossary (fixed translations)

One entry per line: term → translation (also accepts ->, =>, =, or TAB). Example: API → API, homepage → صفحه اصلی. Glossary entries are mandatory for the model.

Per-site preferences

Translate a site once, then reload — the extension remembers the target language per domain. With auto-translate on, future visits to that domain translate automatically.

Keyboard shortcut

Toggle translation: Ctrl+Shift+Y / Cmd+Shift+Y. Change it in your browser's extension shortcuts page (e.g. brave://extensions/shortcuts).
