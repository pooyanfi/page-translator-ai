Installing the CLI

You can install the tool with npm install -g example-cli or download a prebuilt binary.

After installation, run example init in your project directory. The command creates a config.json file and prints the path.

Requirements

  • Node.js 20 or newer
  • An API key from the dashboard

Configuration

Open the configuration file and set the apiKey field. Do not commit this file to version control.

{
  "apiKey": "sk-...",
  "region": "eu-west-1"
}

Common problems

ErrorMeaning
401The key is missing or expired. Generate a new key.
ECONNREFUSEDThe local server is not running. Start it with example serve.

Note: version 2 changed the default port from 8080 to 3000.
