# AI Page Translator — अपने AI से वेब का अनुवाद करें

**अपनी पसंद के AI प्रदाता से किसी भी वेब पेज का अपनी भाषा में अनुवाद करें — कोई बैकएंड नहीं, कोई खाता नहीं, कोई ट्रैकिंग नहीं और प्रति शब्द कोई शुल्क नहीं।**

`Manifest V3` · `कोई बिल्ड चरण नहीं` · `शुद्ध JavaScript` · `संस्करण 1.3.1` · `22 भाषाएँ`

यह फ़ाइल [अंग्रेज़ी मानक README](README.md) का हिन्दी अनुवाद है। किसी अंतर की स्थिति में अंग्रेज़ी पाठ मान्य होगा।

AI Page Translator **Brave** और Chromium आधारित अन्य ब्राउज़रों के लिए एक एक्सटेंशन है। प्रदाता आप स्वयं चुनते हैं: Google Gemini की निःशुल्क कुंजी, OpenAI के अनुरूप कोई भी सेवा (OpenRouter, Groq, NVIDIA, OpenAI…), या **Ollama** के ज़रिए पूर्णतः स्थानीय मॉडल। एक्सटेंशन आपके पढ़े जा रहे पेज का वहीं अनुवाद करता है और उसका लेआउट, लिंक तथा फ़ॉर्मेटिंग बनाए रखता है।

कोई पाठ किसी मध्यस्थ अनुवाद सेवा से नहीं गुज़रता। API कुंजी ब्राउज़र से बाहर नहीं जाती, कोई विश्लेषण उपकरण नहीं है, और Ollama के साथ पाठ आपके कंप्यूटर से भी बाहर नहीं जाता।

> **स्थिति:** संस्करण 1.3.1 · 95 स्वचालित परीक्षण · 12-बिंदु सत्यापन · कोई टेलीमेट्री नहीं, कोई दूरस्थ कोड नहीं।

## एक और अनुवादक क्यों?

अधिकांश पेज अनुवादक एक बार में एक वाक्य भेजते हैं। इसलिए परिणाम पेज के बजाय वाक्यों के ढेर जैसा लगता है: संदर्भ खो जाता है, शब्दावली बदलती रहती है, लिंक वाक्यों को बीच से काट देते हैं, और लक्ष्य भाषा स्रोत भाषा का शब्द क्रम विरासत में ले लेती है।

यह एक्सटेंशन पाठ नोड्स के बजाय **ब्लॉक** का अनुवाद करता है:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

पूरा ब्लॉक एक इकाई के रूप में भेजा जाता है और इनलाइन मार्कअप की जगह क्रमांकित टोकन ले लेते हैं:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` वाक्य से जुड़ी इनलाइन सामग्री (लिंक, ज़ोर, span) को दर्शाता है, और `<vN/>` ऐसी सामग्री को जिसका अनुवाद कभी नहीं होना चाहिए (कोड, चित्र, फ़ॉर्म नियंत्रण, विजेट)। मॉडल टोकन हिला सकता है, इसलिए वह अंग्रेज़ी क्रम में बंधने के बजाय लिंक के **चारों ओर** स्वाभाविक लक्ष्य-भाषा वाक्य बनाता है।

वापसी पर उत्तर को पेज छूने से पहले जाँचा जाता है। हर टोकन मौजूद, संतुलित और अद्वितीय होना चाहिए; लिंक गिराने वाला अनुवाद अस्वीकार होता है, कड़े निर्देश के साथ एक बार दोहराया जाता है, और फिर भी सही न हो तो ज्यों का त्यों छोड़ दिया जाता है। मूल एलिमेंट नोड्स फिर उपयोग होते हैं, इसलिए `href`, इवेंट श्रोता और नेस्टेड मार्कअप बचे रहते हैं। «मूल दिखाएँ» ठीक वही मूल नोड्स लौटाता है।

## विशेषताएँ

- **पूरे पेज का वहीं अनुवाद** — शीर्षक, अनुच्छेद, सूचियाँ, तालिकाएँ, कैप्शन और बटन।
- **लिंक और इनलाइन फ़ॉर्मेटिंग सुरक्षित** — टोकन सत्यापन के साथ; खोया लिंक कभी चुपचाप लागू नहीं होता।
- **स्वाभाविक या शब्दशः शैली** — *स्वाभाविक* (डिफ़ॉल्ट) देशी लेखक की तरह पुनर्लेखन करती है; *शब्दशः* तकनीकी पेजों पर स्रोत के करीब रहती है।
- **प्रत्येक भाषा के लिए शैली मार्गदर्शिका** — फ़ारसी, अरबी, उर्दू और हिब्रू के लिए विशेष निर्देश, तथा अन्य 18 भाषाओं के लिए सामान्य मार्गदर्शिका।
- **निश्चित टाइपोग्राफ़ी सुधार** — फ़ारसी `ی`/`ک`, `می`/`ها`/`تر` में शून्य-चौड़ाई रिक्ति, और `، ؛ ؟` मॉडल की गलती पर भी ठीक होते हैं।
- **वैकल्पिक गुणवत्ता जाँच** — हर खंड को {स्रोत, अनुवाद} युग्म के रूप में पढ़ती है, इसलिए केवल शब्द नहीं, अर्थ भी सुधारती है।
- **शब्दावली** — «शब्द → अनुवाद» युग्म जिनका मॉडल को पालन करना होता है।
- **संरक्षित सामग्री** — `<pre>`, `<code>`, URL, ईमेल, `translate="no"`, `contenteditable`, SVG, फ़ॉर्म नियंत्रण और एक्सटेंशन का अपना इंटरफ़ेस कभी नहीं भेजे जाते।
- **विशेषता लेबल** — `alt`, `title`, `placeholder` और `aria-label` अलग चैनल से और अनुच्छेद के बजाय लेबल के लहजे में अनूदित होते हैं।
- **गतिशील पेज** — अनंत स्क्रॉल या SPA की नई सामग्री आते ही अनूदित होती है, बिना अनंत ऑब्ज़र्वर लूप के।
- **दाएँ से बाएँ सही ढंग से** — हर अनूदित ब्लॉक पर `dir`, `<html>` पर `lang`, पूरा पेज पलटे बिना; सब कुछ बहाल हो जाता है।
- **प्रति साइट स्मृति** — हर डोमेन की लक्ष्य भाषा याद रखता है और लोड पर स्वतः अनुवाद कर सकता है।
- **जिसका भी API हो** — Gemini, Ollama और कोई भी OpenAI-अनुरूप एंडपॉइंट, service worker से कॉल होते हैं, इसलिए CORS की समस्या नहीं।
- **मेमोरी कैश, पुनः प्रयास और विभाजन** — एक जैसा पाठ एक बार भेजा जाता है; विफल खंड पूरा पेज गिराने के बजाय बाँटा जाता है; 429/5xx बढ़ती प्रतीक्षा के साथ दोहराए जाते हैं।
- **कोई बिल्ड चरण नहीं** — सादे क्लासिक स्क्रिप्ट, जैसे हैं वैसे लोड होते हैं।

## इंस्टॉल

1. यह रिपॉज़िटरी डाउनलोड करें (**Code → Download ZIP** या `git clone`) और फ़ोल्डर रख लें।
2. `brave://extensions` (या `chrome://extensions`) खोलें।
3. **Developer mode** चालू करें।
4. **Load unpacked** दबाएँ और यही फ़ोल्डर चुनें (जिसमें `manifest.json` है)।
5. पॉपअप एक क्लिक पर चाहिए तो एक्सटेंशन पिन करें।

कोई बिल्ड, इंस्टॉल या बंडलिंग चरण नहीं है। एक्सटेंशन केवल `manifest.json` में सूचीबद्ध फ़ाइलें पढ़ता है; `tests/`, `scripts/`, `bench/`, `docs/` और `.github/` केवल विकास के लिए हैं और कभी लोड नहीं होते।

आधुनिक Chromium ब्राउज़र आवश्यक है। बंद shadow root तब अनूदित होते हैं जब ब्राउज़र API उपलब्ध कराता है (Chromium 119+); बाकी सब पुराने संस्करणों पर भी काम करता है।

## दूसरों के साथ साझा करना

`npm run release` पैकेज बनाता है और फ़ाइलें `release/` में रखता है (यह फ़ोल्डर git में नहीं जाता):

| फ़ाइल | क्या है | इंस्टॉल कैसे होता है |
|---|---|---|
| `page-translator-ai-<version>.zip` | पूरा एक्सटेंशन, लगभग 95 KB, अंदर `INSTALL.txt` के साथ | अनज़िप करें → **Load unpacked**; यही फ़ाइल स्टोर भी स्वीकार करता है |
| `page-translator-ai-<version>.crx` | हस्ताक्षरित पैकेज | `brave://extensions` पर खींचें, जहाँ स्टोर से बाहर इंस्टॉल की अनुमति है |
| `page-translator-ai-signing-key.pem` | हस्ताक्षर कुंजी | इसे कभी साझा न करें; `npm run release` इसे फिर उपयोग करता है ताकि अपडेट के बीच एक्सटेंशन ID एक ही रहे |

यानी आप किसी को एक ही फ़ाइल देते हैं, और उसमें इंस्टॉल के चरण भी हैं।

**एक स्पष्ट सीमा:** ब्राउज़र एक्सटेंशन क्लाइंट-साइड कोड है। जो भी इसे इंस्टॉल करेगा वह ये फ़ाइलें पढ़ सकता है — `.crx` हस्ताक्षरित zip है और बिना पैकेज वाला एक्सटेंशन साधारण फ़ोल्डर। कोई पैकेजिंग या अस्पष्टीकरण इसे नहीं बदलता; मिनिफ़िकेशन केवल पढ़ना धीमा करता है और स्टोर की नीति अस्पष्टीकरण मना करती है। यदि स्रोत वास्तव में गुप्त रहना चाहिए, तो एकमात्र व्यावहारिक विकल्प प्रॉम्प्ट और प्रदाता कॉल को अपने सर्वर पर ले जाना है, जिसका अर्थ «अपनी कुंजी, बिना बैकएंड» डिज़ाइन छोड़ना है।

रिपॉज़िटरी दिए बिना वितरण के लिए zip को Chrome Web Store पर **निजी या असूचीबद्ध** आइटम के रूप में प्रकाशित करें; गैर-तकनीकी उपयोगकर्ता के लिए एक-क्लिक इंस्टॉल का यही एकमात्र रास्ता है।

## प्रदाता कॉन्फ़िगर करें

एक्सटेंशन पॉपअप → **Options & settings**, या `brave://extensions` → विवरण → एक्सटेंशन विकल्प।

| प्रदाता | एंडपॉइंट | कुंजी | टिप्पणियाँ |
|---|---|---|---|
| **Ollama** (स्थानीय) | `http://localhost:11434` | कोई नहीं | निःशुल्क और पूर्णतः निजी। [ollama.com](https://ollama.com) से इंस्टॉल करें, फिर `ollama run llama3` चलाएँ। 403 मिले तो `OLLAMA_ORIGINS=chrome-extension://*` के साथ फिर शुरू करें। |
| **Google Gemini** | `generativelanguage.googleapis.com` | [AI Studio](https://aistudio.google.com/app/apikey) से निःशुल्क कुंजी | वर्तमान मॉडल ID इस्तेमाल करें, जैसे `gemini-2.5-flash`. निःशुल्क सीमाएँ बदलती हैं; Google की मॉडल सूची देखें। |
| **OpenAI-अनुरूप** | आपका एंडपॉइंट, जैसे `https://openrouter.ai/api/v1`, `https://api.groq.com/openai/v1`, `https://integrate.api.nvidia.com/v1` | प्रदाता की कुंजी | कोई भी सेवा जो `/chat/completions` समझती हो। इंटरफ़ेस में सुझाए मॉडल केवल उदाहरण हैं; प्रदाता की सूची से सटीक ID लें। |

फिर:

1. **डिफ़ॉल्ट लक्ष्य भाषा** चुनें।
2. **अनुवाद शैली** चुनें: *Natural* (सुझाया गया) या *Literal*।
3. चाहें तो **Quality mode** चालू करें और **शब्दावली** में प्रविष्टियाँ जोड़ें, प्रति पंक्ति एक (`शब्द → अनुवाद`; `->`, `=>`, `=` और TAB भी चलते हैं)।
4. **स्रोत भाषा** को *Auto-detect* पर रखें या स्वयं चुनें।
5. **Test connection** और फिर **Save settings** दबाएँ।

प्रदाता संबंधी टिप्पणियाँ:

- **Gemini की सोच सेटिंग मॉडल पीढ़ी के अनुसार चुनी जाती है।** 2.5 Flash और Flash-Lite बिना सोच के चलते हैं, 2.5 Pro न्यूनतम बजट (128) और 3.x/4.x निम्न स्तर लेते हैं। यदि मॉडल सेटिंग अस्वीकार करे, अनुरोध एक बार उसके बिना दोहराया जाता है।
- **Ollama** 8192 टोकन की संदर्भ विंडो के साथ कॉल होता है; कम संदर्भ पर प्रशिक्षित मॉडल लंबे पेज फिर भी काटेगा — इसलिए पेज छोटी इकाइयों में बाँटा जाता है।
- **निःशुल्क योजनाएँ** गति सीमित करती हैं। एक्सटेंशन प्रतीक्षा कर पुनः प्रयास करता है; पाठ चुपचाप नहीं गिराता।

## यह कैसे काम करता है

```
पेज का DOM
  └─ content script: ब्लॉक इकाइयाँ इकट्ठा करना, इनलाइन मार्कअप को <tN>/<vN/> टोकन में बदलना
       └─ विभाजक: प्रति अनुरोध 24 इकाइयाँ / 2400 अक्षर
            └─ service worker: आपके प्रदाता को अनुरोध (एक्सटेंशन मूल, बिना CORS)
                 └─ प्रदाता: JSON अंदर, JSON बाहर, ID सुरक्षित
                      └─ सत्यापन: टोकन पूर्ण, संतुलित और अद्वितीय; ID मेल खाते हैं
                           └─ DOM: मूल एलिमेंट नोड्स का पुनः उपयोग, केवल पाठ लिखना
                                └─ MutationObserver: बाद में जोड़ी गई सामग्री का अनुवाद
```

वे निर्णय जो वास्तव में फ़र्क़ डालते हैं:

- **प्रदाता तक ट्रैफ़िक कभी पेज संदर्भ से बाहर नहीं जाता।** content script `AIPT_FETCH` संदेश भेजता है; service worker अनुरोध करता है, इसलिए सख्त CORS वाले एंडपॉइंट भी जैसे हैं वैसे काम करते हैं। service worker `sender.id` भी जाँचता है, ताकि केवल यही एक्सटेंशन इसे प्रॉक्सी के रूप में उपयोग कर सके।
- **प्रॉम्प्ट एक अनुबंध है, इच्छा नहीं।** ID अंदर, ID बाहर; प्रति खंड एक प्रविष्टि; टैग अछूते; संख्याएँ, URL, कोड और placeholder ज्यों के त्यों; कोई अतिरिक्त व्याख्या नहीं। उत्तर ID से पढ़े जाते हैं, इसलिए बदले क्रम या आंशिक रूप से ख़राब ऐरे अनुवादों को खिसकाने के बजाय सुरक्षित रूप से विफल होते हैं।
- **हर भाषा की अपनी शैली मार्गदर्शिका है।** उदाहरण के लिए फ़ारसी मार्गदर्शिका फ़ारसी शब्द क्रम और क्रिया माँगती है (`بررسی کنید`, न कि `بررسی را انجام دهید`), जहाँ साधारण वाक्य काफ़ी है वहाँ `می‌باشد`/`بایستی`/`گردید` मना करती है, लैटिन लिपि में केवल वास्तविक उधार-शब्द रखती है और विराम-चिह्न तथा शून्य-चौड़ाई रिक्ति सुधारती है। few-shot उदाहरण मॉडल को लक्ष्य दिखाते हैं, केवल वर्णन नहीं करते।
- **दिशा स्थानीय है।** फ़ारसी, अरबी, हिब्रू और उर्दू ब्लॉक `dir="rtl"` पाते हैं, `<html>` लक्ष्य भाषा पाता है और बाकी पेज अपनी ज्यामिति रखता है — पूरा पेज पलटने से केंद्रित लेआउट और कोड ब्लॉक टूटते थे। दोनों मूल पाठ के साथ बहाल होते हैं।
- **विफलताएँ दिखती हैं और सीमित रहती हैं।** जो खंड पढ़ा न जा सके वह बाँटा जाता है; जो इकाई फिर भी विफल हो वह स्रोत भाषा में रहती है और ऊपर की पट्टी में बताई जाती है। अनुवाद के बीच रद्द करना साफ़ रुकता है और आधा लिखा DOM नहीं छोड़ता।

अधिक विवरण: [`docs/translation-quality-design.md`](../translation-quality-design.md).

## गोपनीयता और अनुमतियाँ

| अनुमति | क्यों आवश्यक है |
|---|---|
| `storage` | सेटिंग्स, API कुंजी, शब्दावली और प्रति-साइट प्राथमिकताएँ `chrome.storage.local` में सहेजना। |
| `contextMenus` | राइट-क्लिक «इस पेज / चयन का अनुवाद करें»। |
| `tabs` | सक्रिय टैब को संदेश भेजना और विकल्प खोलना। |
| `activeTab` | उस पेज पर कार्य करना जिसका अनुवाद आप स्वयं करते हैं। |
| `<all_urls>` | देखे गए पेजों में content script डालना और service worker को प्रदाता एंडपॉइंट कॉल करने देना। |

- API कुंजी केवल इसी ब्राउज़र के स्थानीय भंडार में रहती है और केवल आपके चुने प्रदाता को जाती है।
- कोई विश्लेषण नहीं, कोई टेलीमेट्री नहीं, कोई दूरस्थ कोड नहीं, डेवलपर सर्वर से कोई संपर्क नहीं, कोई खाता नहीं।
- सारा पाठ `textContent` / `createTextNode` से लिखा जाता है; एक्सटेंशन में कहीं `innerHTML`, `eval` या `new Function` नहीं है। मॉडल का आउटपुट पेज तक केवल पाठ के रूप में पहुँचता है, और विशेषताएँ एक निश्चित अनुमत-सूची तक सीमित हैं — `href`, `src` और इवेंट हैंडलर कभी मॉडल आउटपुट से नहीं लिखे जाते।
- प्रति-साइट प्राथमिकताएँ service worker में एक ही क्रमबद्ध लेखक लिखता है, इसलिए दो टैब एक-दूसरे को मिटा नहीं सकते।
- स्वचालित भाषा पहचान उसी प्रदाता को अधिकतम 600 अक्षरों का नमूना भेजती है; स्रोत भाषा स्वयं चुनने पर यह अनुरोध पूरी तरह हट जाता है।

सुरक्षा नीति और भेद्यता की रिपोर्ट: [`SECURITY.md`](../../SECURITY.md).

## ज्ञात सीमाएँ

- **टोकन सत्यापन जानबूझकर सख्त है।** जो मॉडल `<tN>` लगातार बिगाड़ता है वह उन अनुच्छेदों को स्रोत भाषा में छोड़ देगा (और बता देगा) बजाय लिंक गिराने के। ऐसा मॉडल चुनें जो संरचित आउटपुट का पालन करे; *Test connection* टोकन वाला वाक्य आज़माता है।
- **गुणवत्ता मॉडल पर निर्भर है।** छोटे स्थानीय मॉडल उपयोगी हैं पर Gemini या GPT-श्रेणी के मॉडलों जितने प्रवाही नहीं; शैली परत मदद करती है, ज्ञान नहीं जोड़ती।
- **बंद shadow root और cross-origin iframe** एक्सटेंशन की पहुँच से बाहर हैं (ब्राउज़र सुरक्षा)। खुले shadow root और समान-मूल फ़्रेम संभाले जाते हैं।
- **ढीले पाठ वाले मिश्रित कंटेनर** (`<div>पाठ<p>…</p></div>`) उस पाठ के लिए नोड-दर-नोड अनुवाद पर लौटते हैं; सुगठित पेज इस स्थिति तक नहीं पहुँचते।
- **कैश मेमोरी में है** (प्रति टैब सत्र)। पेज दोबारा लोड करने पर पाठ फिर माँगा जाता है।
- **PDF का अनुवाद नहीं होता**; अंतर्निहित PDF व्यूअर एक्सटेंशन के लिए स्क्रिप्ट-योग्य नहीं है।
- **निःशुल्क योजनाएँ बदलती हैं।** दर सीमाएँ और मॉडल नाम प्रदाता तय करता है, यह एक्सटेंशन नहीं।

## परियोजना की स्थिति और परीक्षण

संस्करण 1.3.1. स्वचालित सूट DOM परत, प्रॉम्प्ट और पार्सिंग, प्रदाताओं के अनुरोध का स्वरूप, इंजन का व्यवहार और Options इंटरफ़ेस को कवर करता है — **95 परीक्षण** — और `npm run verify` 12-बिंदु सत्यापन जोड़ता है: सिंटैक्स, परीक्षण सूट, HTML सिंक पर रोक, कुंजी लीक जाँच, क्लासिक content scripts, संस्करण समानता, CHANGELOG कवरेज और पैकेजिंग।

```bash
npm install       # केवल विकास: DOM परीक्षणों के लिए jsdom
npm test          # 95 परीक्षण
npm run bench     # विभाजन बेंचमार्क, बिना API कुंजी
npm run verify    # सिंटैक्स + परीक्षण + नीति जाँच + पैकेजिंग
npm run package   # केवल वितरण-योग्य फ़ाइलें dist/ में कॉपी
npm run release   # dist और वितरण के लिए release/*.zip, *.crx, *.pem
```

बेंचमार्क विभाजन मापता है, अनुवाद गुणवत्ता नहीं: चार नमूना पेजों पर स्वतंत्र पाठ-नोड संग्राहक **108 टुकड़े** बनाता है जबकि ब्लॉक संग्राहक **63 इकाइयाँ** (कुल 1.7 गुना कम, समाचार लेख पर **2.5 गुना**), और 25 अक्षरों से छोटे टुकड़े **81 से 34** रह जाते हैं। अनुवाद की गुणवत्ता स्वयं उस मॉडल पर निर्भर है जिसे आप जोड़ते हैं; ब्राउज़र-स्तरीय व्यवहार जिन तक स्वचालित परीक्षण नहीं पहुँचते (RTL रेंडरिंग, टूलटिप, वास्तविक SPA ट्रैफ़िक और प्रदाता त्रुटियाँ) [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) की मैनुअल सूची में हैं।
