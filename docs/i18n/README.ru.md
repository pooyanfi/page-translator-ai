AI Page Translator — расширение для **Brave** и других браузеров на Chromium. Провайдера вы выбираете сами: бесплатный ключ Google Gemini, любой совместимый с OpenAI сервис (OpenRouter, Groq, NVIDIA, OpenAI…) или полностью локальная модель через **Ollama**. Расширение переводит читаемую страницу на месте, сохраняя вёрстку, ссылки и форматирование.

Ни один текст не проходит через посреднический сервис перевода. Ключ API не покидает браузер, аналитики нет, а с Ollama текст не выходит даже за пределы вашего компьютера.

> **Состояние:** версия 1.3.1 · 95 автоматических тестов · проверка из 12 пунктов · без телеметрии и без удалённого кода.

## Зачем ещё один переводчик?

Большинство переводчиков страниц отправляют по одному предложению. Поэтому результат выглядит как стопка предложений, а не страница: теряется контекст, терминология расходится, ссылки разрывают предложения пополам, а целевой язык наследует порядок слов исходного.

Это расширение переводит **блоки**, а не текстовые узлы:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

Блок уходит единым целым, а встроенная разметка заменяется нумерованными токенами:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` обозначает встроенное содержимое, принадлежащее предложению (ссылка, выделение, span), а `<vN/>` — содержимое, которое нельзя переводить никогда (код, изображения, элементы форм, виджеты). Модель может переставлять токены, поэтому строит естественное предложение **вокруг** ссылки, а не втискивает его в английский порядок.

На обратном пути ответ проверяется до того, как что-либо коснётся страницы. Каждый токен должен присутствовать, быть сбалансированным и уникальным; перевод, потерявший ссылку, отклоняется, один раз повторяется со строгим указанием, а затем остаётся без изменений. Исходные узлы используются повторно, поэтому `href`, обработчики событий и вложенная разметка выживают. «Показать оригинал» возвращает ровно исходные узлы.

## Возможности

- **Перевод всей страницы на месте** — заголовки, абзацы, списки, таблицы, подписи и кнопки.
- **Ссылки и встроенное форматирование сохраняются** — с проверкой токенов; потерянная ссылка никогда не применяется молча.
- **Естественный или буквальный стиль** — *Естественный* (по умолчанию) переписывает как носитель языка; *Буквальный* держится ближе к исходнику на технических страницах.
- **Руководства по стилю для языков** — отдельные указания для персидского, арабского, урду и иврита и общее руководство для остальных 18 языков.
- **Детерминированная типографика** — персидские `ی`/`ک`, неразрывные пробелы в `می`/`ها`/`تر` и знаки `، ؛ ؟` исправляются даже при ошибке модели.
- **Необязательный проход качества** — читает каждый сегмент как пару {источник, перевод} и исправляет смысл, а не только формулировку.
- **Глоссарий** — пары «термин → перевод», которые модель обязана соблюдать.
- **Защищённое содержимое** — `<pre>`, `<code>`, URL, адреса почты, `translate="no"`, `contenteditable`, SVG, элементы форм и интерфейс самого расширения никогда не отправляются.
- **Подписи атрибутов** — `alt`, `title`, `placeholder` и `aria-label` идут отдельным каналом и звучат как подписи, а не как абзацы.
- **Динамические страницы** — новый контент из бесконечной прокрутки или SPA переводится по мере появления, без циклов наблюдателя.
- **Правильный RTL** — `dir` на каждом переведённом блоке, `lang` на `<html>`, без переворота всей страницы; всё восстанавливается.
- **Память для сайта** — запоминает целевой язык для домена и умеет переводить автоматически при загрузке.
- **Любой API** — Gemini, Ollama и любая совместимая с OpenAI конечная точка, вызываемые из service worker, поэтому без проблем CORS.
- **Кэш в памяти, повторы и разбиение** — идентичный текст отправляется один раз; сбойный блок делится вместо падения страницы; ошибки 429/5xx повторяются с растущей паузой.
- **Без сборки** — обычные классические скрипты, загружаются как есть.

## Установка

1. Скачайте репозиторий (**Code → Download ZIP** или `git clone`) и сохраните папку.
2. Откройте `brave://extensions` (или `chrome://extensions`).
3. Включите **режим разработчика**.
4. Нажмите **Load unpacked** и выберите эту папку (ту, где лежит `manifest.json`).
5. Закрепите расширение, если хотите попап в один клик.

Никакой сборки, установки или бандлинга нет. Расширение читает только файлы, перечисленные в `manifest.json`; `tests/`, `scripts/`, `bench/`, `docs/` и `.github/` нужны только для разработки и никогда не загружаются.

Нужен актуальный браузер на Chromium. Закрытые shadow root переводятся там, где браузер открывает API (Chromium 119+); всё остальное работает и в старых версиях.

## Как поделиться с другими

`npm run release` собирает пакет и кладёт файлы в `release/` (папка игнорируется git):

| Файл | Что это | Как установить |
|---|---|---|
| `page-translator-ai-<version>.zip` | всё расширение, около 95 КБ, внутри `INSTALL.txt` | распаковать → **Load unpacked**; этот же файл принимает магазин |
| `page-translator-ai-<version>.crx` | подписанный пакет | перетащить на `brave://extensions`, где разрешена установка вне магазина |
| `page-translator-ai-signing-key.pem` | ключ подписи | никогда не передавайте; `npm run release` использует его снова, чтобы ID расширения не менялся между обновлениями |

То есть вы передаёте один файл, и внутри уже есть инструкция по установке.

**Честное ограничение:** расширение браузера — это клиентский код. Любой, кто его установит, может прочитать эти файлы: `.crx` — подписанный zip, а распакованное расширение — обычная папка. Ни упаковка, ни обфускация этого не меняют; минификация лишь замедляет читателя, а правила магазинов обфускацию запрещают. Если исходный код должен оставаться тайной, единственный разумный вариант — перенести промпты и обращения к провайдеру на ваш сервер, отказавшись от схемы «свой ключ, без сервера».

Чтобы распространять без передачи репозитория, опубликуйте zip как **приватный или непубличный** элемент Chrome Web Store; только так нетекнический пользователь установит расширение в один клик.

## Настройка провайдера

Попап расширения → **Options & settings**, или `brave://extensions` → Подробнее → Параметры расширения.

| Провайдер | Конечная точка | Ключ | Примечания |
|---|---|---|---|
| **Ollama** (локально) | `http://localhost:11434` | не нужен | Бесплатно и полностью приватно. Установите с [ollama.com](https://ollama.com), затем `ollama run llama3`. При 403 перезапустите с `OLLAMA_ORIGINS=chrome-extension://*`. |
| **Google Gemini** | `generativelanguage.googleapis.com` | бесплатный ключ из [AI Studio](https://aistudio.google.com/app/apikey) | Используйте актуальный ID модели, например `gemini-2.5-flash`. Бесплатные лимиты меняются; смотрите список моделей Google. |
| **Совместимый с OpenAI** | ваша конечная точка, например `https://openrouter.ai/api/v1`, `https://api.groq.com/openai/v1`, `https://integrate.api.nvidia.com/v1` | ключ провайдера | Любой сервис с `/chat/completions`. Модели, предложенные в интерфейсе, — примеры; берите точный ID из каталога провайдера. |

Затем:

1. Выберите **язык перевода по умолчанию**.
2. Выберите **стиль перевода**: *Natural* (рекомендуется) или *Literal*.
3. При желании включите **Quality mode** и добавьте записи **глоссария**, по одной в строке (`термин → перевод`; работают также `->`, `=>`, `=` и TAB).
4. Оставьте **язык источника** на *Auto-detect* или выберите его явно.
5. Нажмите **Test connection**, затем **Save settings**.

Замечания о провайдерах:

- **Настройка рассуждений Gemini зависит от поколения модели.** 2.5 Flash и Flash-Lite работают без рассуждений, 2.5 Pro использует минимум (128), 3.x/4.x — низкий уровень. Если модель не принимает настройку, запрос повторяется один раз без неё.
- **Ollama** вызывается с окном контекста 8192 токена; модель, обученная на меньшем, всё равно обрежет длинные страницы — поэтому страница делится на небольшие единицы.
- **Бесплатные тарифы** ограничивают частоту. Расширение ждёт и повторяет; текст никогда не пропадает молча.

## Использование

- Нажмите значок → выберите язык → **Translate this page**.
- **Show original / Show translation** в любой момент; восстановление без потерь.
- Наведите курсор на переведённый абзац, чтобы увидеть оригинал.
- Правый клик → **Translate this page** или **Translate selection**.
- Клавиатура: `Ctrl+Shift+Y` (`Cmd+Shift+Y` в macOS) переключает перевод; меняется на странице сочетаний клавиш браузера.
- При включённом **Auto-translate** и сохранённом предпочтении сайта подходящие страницы переводятся при загрузке.
- Настройки применяются к открытым вкладкам при следующем переводе; перезагрузка не нужна.

## Как это работает

```
DOM страницы
  └─ content script: собирает блочные единицы, сериализует встроенную разметку в токены <tN>/<vN/>
       └─ разбиение: 24 единицы / 2400 символов на запрос
            └─ service worker: запрос к вашему провайдеру (происхождение расширения, без CORS)
                 └─ провайдер: JSON на входе, JSON на выходе, ID сохраняются
                      └─ проверка: токены полные, сбалансированные и уникальные; ID совпадают
                           └─ DOM: повторное использование исходных узлов, запись только текста
                                └─ MutationObserver: перевод добавленного позже содержимого
```

Решения, которые действительно важны:

- **Трафик к провайдеру никогда не уходит из контекста страницы.** Content script отправляет сообщение `AIPT_FETCH`; service worker выполняет запрос, поэтому конечные точки со строгим CORS работают без изменений. Service worker также проверяет `sender.id`, так что только это расширение может использовать его как прокси.
- **Промпт — это договор, а не пожелание.** ID на входе, ID на выходе; одна запись на сегмент; теги неприкосновенны; числа, URL, код и placeholder дословно; никаких добавленных пояснений. Ответы читаются по ID, поэтому переставленный или частично искажённый массив безопасно падает, а не сдвигает переводы.
- **У каждого языка своё руководство по стилю.** Персидское руководство, например, требует персидского порядка слов и глаголов (`بررسی کنید`, а не `بررسی را انجام دهید`), запрещает `می‌باشد`/`بایستی`/`گردید` там, где достаточно обычного предложения, оставляет в латинице только настоящие заимствования и исправляет пунктуацию и неразрывные пробелы. Примеры few-shot показывают модели цель, а не описывают её.
- **Направление остаётся локальным.** Персидские, арабские, ивритские и урду-блоки получают `dir="rtl"`, `<html>` получает целевой язык, остальная страница сохраняет геометрию: глобальный переворот ломал центрированные макеты и блоки кода. И то и другое восстанавливается вместе с исходным текстом.
- **Ошибки видны и ограничены.** Нечитаемый блок делится; единица, которая всё равно не проходит, остаётся на исходном языке и отмечается в верхней панели. Отмена посреди перевода останавливается чисто и не оставляет недописанный DOM.

Подробнее: [`docs/translation-quality-design.md`](../translation-quality-design.md).

## Конфиденциальность и разрешения

| Разрешение | Зачем нужно |
|---|---|
| `storage` | Хранить настройки, ключ API, глоссарий и предпочтения сайтов в `chrome.storage.local`. |
| `contextMenus` | Пункт контекстного меню «Перевести страницу / выделение». |
| `tabs` | Отправлять сообщения активной вкладке и открывать параметры. |
| `activeTab` | Действовать на странице, которую вы явно переводите. |
| `<all_urls>` | Внедрять content script в посещаемые страницы и разрешать service worker вызывать настроенную конечную точку. |

- Ключ API хранится только в локальном хранилище этого браузера и отправляется только выбранному провайдеру.
- Без аналитики, телеметрии, удалённого кода, обращений к серверу автора и без аккаунта.
- Весь текст записывается через `textContent` / `createTextNode`; `innerHTML`, `eval` или `new Function` нигде нет. Вывод модели попадает на страницу только как текст, а атрибуты ограничены фиксированным списком — `href`, `src` и обработчики событий никогда не записываются из вывода модели.
- Предпочтения сайтов пишет один сериализованный писатель в service worker, поэтому две вкладки не затирают друг друга.
- Автоопределение языка отправляет тому же провайдеру не более 600 символов; если выбрать язык источника вручную, этот запрос исчезает.

Политика безопасности и сообщение об уязвимости: [`SECURITY.md`](../../SECURITY.md).

## Известные ограничения

- **Проверка токенов намеренно строгая.** Модель, которая систематически ломает `<tN>`, оставит такие абзацы на исходном языке (и сообщит об этом), а не потеряет ссылку. Используйте модель, соблюдающую структурированный вывод; *Test connection* проверяет предложение с токенами.
- **Качество зависит от модели.** Небольшие локальные модели пригодны, но менее плавны, чем Gemini или модели класса GPT; стилевой слой помогает, но не добавляет знаний.
- **Закрытые shadow root и cross-origin iframe** вне досягаемости расширения (безопасность браузера). Открытые shadow root и фреймы того же происхождения поддерживаются.
- **Смешанные контейнеры со свободным текстом** (`<div>текст<p>…</p></div>`) для этого текста возвращаются к переводу узел за узлом; корректные страницы до этого не доходят.
- **Кэш в памяти** (на сессию вкладки). Перезагрузка страницы снова запрашивает текст.
- **PDF не переводятся**; встроенная просмотрщица PDF недоступна для скриптов расширений.
- **Бесплатные тарифы меняются.** Лимиты частоты и названия моделей определяет провайдер, а не это расширение.

```bash
npm run release   # dist + release/*.zip, *.crx, *.pem для распространения
```

Замер измеряет сегментацию, а не качество перевода: на четырёх примерах независимый сборщик текстовых узлов даёт **108 фрагментов**, а блочный сборщик — **63 единицы** (всего в 1,7 раза меньше, **в 2,5 раза** на новостной статье), а фрагменты короче 25 символов сокращаются с **81 до 34**. Само качество перевода по-прежнему зависит от подключённой модели; ручной чек-лист в [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) покрывает то, чего не достигают автотесты (отрисовка RTL, подсказки, реальный трафик SPA, ошибки провайдера).

CI запускает `npm run verify` и `npm run bench` на Node 20 и 22 при каждом push и pull request ([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).

## Участие в разработке

Issues и pull request приветствуются. Перед отправкой изменения запустите `npm run verify`; сохраняйте расширение без сборки, держите трафик к провайдеру в service worker и никогда не добавляйте `innerHTML`. Если меняете промпт, добавьте или обновите тест: промпт, парсер и нормализатор тестируются вместе, потому что работают только как набор.

Полные правила, политика переводов `docs/i18n/` и соглашения о коммитах — в [`CONTRIBUTING.md`](../../CONTRIBUTING.md).
