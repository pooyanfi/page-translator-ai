AI Page Translator **Brave** اور Chromium پر مبنی دیگر براؤزرز کے لیے ایک ایکسٹینشن ہے۔ فراہم کنندہ آپ خود منتخب کرتے ہیں: Google Gemini کی مفت کلید، OpenAI سے ہم آہنگ کوئی بھی سروس (OpenRouter، Groq، NVIDIA، OpenAI…)، یا **Ollama** کے ذریعے مکمل مقامی ماڈل۔ ایکسٹینشن آپ کے پڑھے ہوئے صفحے کو اسی جگہ ترجمہ کرتا ہے اور اس کی ترتیب، روابط اور فارمیٹنگ برقرار رکھتا ہے۔

کوئی متن کسی درمیانی ترجمہ سروس سے نہیں گزرتا۔ آپ کی API کلید براؤزر سے باہر نہیں جاتی، کوئی تجزیاتی ٹول موجود نہیں، اور Ollama کے ساتھ متن آپ کے کمپیوٹر سے بھی باہر نہیں جاتا۔

## ایک اور مترجم کیوں؟

زیادہ تر صفحہ مترجم ایک وقت میں ایک جملہ بھیجتے ہیں۔ اسی لیے نتیجہ صفحے کے بجائے جملوں کے ڈھیر جیسا لگتا ہے: سیاق و سباق ضائع ہو جاتا ہے، اصطلاحات بدلتی رہتی ہیں، روابط جملوں کو درمیان سے کاٹ دیتے ہیں، اور ہدف زبان ماخذ زبان کی الفاظ کی ترتیب ورثے میں لے لیتی ہے۔

یہ ایکسٹینشن متن کے نوڈز کے بجائے **بلاکس** کا ترجمہ کرتا ہے:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

پورا بلاک ایک اکائی کے طور پر بھیجا جاتا ہے اور اندرونی مارک اپ کی جگہ شمار شدہ ٹوکن لیتے ہیں:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` جملے سے متعلق اندرونی مواد (رابطہ، تاکید، span) کی نشان دہی کرتا ہے، اور `<vN/>` ایسے مواد کی جو کبھی ترجمہ نہیں ہونا چاہیے (کوڈ، تصاویر، فارم کنٹرول، ویجٹ)۔ ماڈل ٹوکن آگے پیچھے کر سکتا ہے، اس لیے وہ قدرتی ہدف زبان کا جملہ **رابطے کے گرد** بناتا ہے، انگریزی ترتیب میں جکڑا نہیں جاتا۔

واپسی پر صفحے کو چھونے سے پہلے جواب کی توثیق ہوتی ہے۔ ہر ٹوکن موجود، متوازن اور منفرد ہونا چاہیے؛ جو ترجمہ رابطہ گرا دے وہ مسترد ہوتا ہے، ایک بار سخت ہدایت کے ساتھ دہرایا جاتا ہے، اور پھر بھی درست نہ ہو تو بلاک جوں کا توں رہتا ہے۔ صفحے کے اصل نوڈز دوبارہ استعمال ہوتے ہیں، اس لیے `href`، ایونٹ سننے والے اور اندرونی مارک اپ محفوظ رہتے ہیں۔ «اصل دکھائیں» بالکل وہی اصل نوڈز واپس لاتا ہے۔

## خصوصیات

- **پورے صفحے کا اسی جگہ ترجمہ** — سرخیاں، پیراگراف، فہرستیں، جدولیں، کیپشن اور بٹن۔
- **روابط اور اندرونی فارمیٹنگ محفوظ** — ٹوکن توثیق کے ساتھ؛ گم شدہ رابطہ کبھی خاموشی سے نافذ نہیں ہوتا۔
- **قدرتی یا لفظی انداز** — «قدرتی» (پیش فرض) مقامی مصنف کی طرح دوبارہ لکھتا ہے؛ «لفظی» تکنیکی صفحات میں ماخذ کے قریب رہتا ہے۔
- **ہر زبان کے لیے اندازِ بیان کی رہنمائی** — فارسی، عربی، اردو اور عبرانی کے لیے مخصوص رہنمائی، اور باقی 18 زبانوں کے لیے عمومی رہنمائی۔
- **متعین رسم الخط کی اصلاح** — فارسی `ی`/`ک`، `می`/`ها`/`تر` میں زیرو اسپیس، اور `، ؛ ؟` ماڈل کی غلطی کے باوجود درست کیے جاتے ہیں۔
- **اختیاری معیار کا جائزہ** — ہر قطعے کو {ماخذ، ترجمہ} کے جوڑ کے طور پر پڑھتا ہے، اس لیے صرف الفاظ نہیں، معنی بھی درست کرتا ہے۔
- **اصطلاحات کی لغت** — «اصطلاح ← ترجمہ» کے جوڑ جن کی ماڈل کو پابندی کرنی ہوتی ہے۔
- **محفوظ مواد** — `<pre>`، `<code>`، یو آر ایل، ای میل، `translate="no"`، `contenteditable`، SVG، فارم کنٹرول اور خود ایکسٹینشن کا انٹرفیس کبھی نہیں بھیجے جاتے۔
- **خصوصیات کے لیبل** — `alt`، `title`، `placeholder` اور `aria-label` الگ چینل سے اور پیراگراف کے بجائے لیبل کے لہجے میں ترجمہ ہوتے ہیں۔
- **متحرک صفحات** — لامتناہی اسکرول یا SPA کا نیا مواد ظاہر ہوتے ہی ترجمہ ہو جاتا ہے، بغیر لامتناہی آبزرور لوپ کے۔
- **دائیں سے بائیں درست طریقے سے** — ہر ترجمہ شدہ بلاک پر `dir`، `<html>` پر `lang`، پورا صفحہ پلٹائے بغیر؛ سب کچھ بحال ہو جاتا ہے۔
- **فی سائٹ یادداشت** — ہر ڈومین کی ہدف زبان یاد رکھتا ہے اور لوڈ پر خودکار ترجمہ کر سکتا ہے۔
- **ہر API والی سروس** — Gemini، Ollama اور کوئی بھی OpenAI سے ہم آہنگ اینڈ پوائنٹ، service worker سے کال ہوتے ہیں، اس لیے CORS کا مسئلہ نہیں۔
- **میموری کیش، دوبارہ کوشش اور تقسیم** — یکساں متن ایک بار بھیجا جاتا ہے؛ ناکام قطعہ تقسیم ہوتا ہے، صفحہ نہیں ٹوٹتا؛ 429/5xx بڑھتی تاخیر کے ساتھ دہرائے جاتے ہیں۔
- **کوئی بلڈ مرحلہ نہیں** — سادہ کلاسک اسکرپٹس، جیسے ہیں ویسے ہی لوڈ ہوتے ہیں۔

## تنصیب

1. یہ ریپوزٹری ڈاؤن لوڈ کریں (**Code → Download ZIP** یا `git clone`) اور فولڈر رکھ لیں۔
2. `brave://extensions` (یا `chrome://extensions`) کھولیں۔
3. **Developer mode** آن کریں۔
4. **Load unpacked** پر کلک کریں اور یہی فولڈر منتخب کریں (جس میں `manifest.json` ہے)۔
5. اگر پاپ اپ ایک کلک پر چاہیے تو ایکسٹینشن پن کریں۔

کوئی بلڈ، تنصیب یا بنڈلنگ مرحلہ نہیں۔ ایکسٹینشن صرف وہی فائلیں پڑھتا ہے جو `manifest.json` میں درج ہیں؛ `tests/`، `scripts/`، `bench/`، `docs/` اور `.github/` صرف ترقی کے لیے ہیں اور کبھی لوڈ نہیں ہوتے۔

موجودہ Chromium براؤزر درکار ہے۔ بند شیڈو روٹس وہاں ترجمہ ہوتے ہیں جہاں براؤزر API فراہم کرتا ہے (Chromium 119 اور بعد)؛ باقی سب پرانے ورژنز پر بھی کام کرتا ہے۔

## دوسروں کے ساتھ شیئر کرنا

`npm run release` پیکیج بناتا ہے اور فائلیں `release/` میں رکھتا ہے (یہ فولڈر git میں شامل نہیں):

| فائل | کیا ہے | تنصیب کیسے ہوتی ہے |
|---|---|---|
| `page-translator-ai-<version>.zip` | مکمل ایکسٹینشن، تقریباً 95 کلو بائٹ، اندر `INSTALL.txt` کے ساتھ | ان زپ کریں اور **Load unpacked**؛ یہی فائل اسٹور بھی قبول کرتا ہے |
| `page-translator-ai-<version>.crx` | دستخط شدہ پیکیج | `brave://extensions` پر گھسیٹیں، جہاں اسٹور سے باہر تنصیب کی اجازت ہے |
| `page-translator-ai-signing-key.pem` | دستخط کی کلید | کبھی شیئر نہ کریں؛ `npm run release` اسی کو دوبارہ استعمال کرتا ہے تاکہ اپ ڈیٹس میں ایکسٹینشن کا شناختی نمبر ایک ہی رہے |

یعنی آپ کسی کو جو چیز دیتے ہیں وہ ایک فائل ہے، اور اس میں تنصیب کے مراحل بھی موجود ہیں۔

**ایک کھلی حقیقت:** براؤزر ایکسٹینشن کلائنٹ سائیڈ کوڈ ہے۔ جو بھی اسے نصب کرے وہ یہ فائلیں پڑھ سکتا ہے — `.crx` ایک دستخط شدہ zip ہے اور غیر پیک شدہ ایکسٹینشن ایک عام فولڈر۔ کوئی پیکیجنگ یا مبہم کاری اسے نہیں بدلتی؛ مبہم کاری صرف پڑھنے کو سست کرتی ہے اور اسٹور کی پالیسی اسے منع کرتی ہے۔ اگر کوڈ واقعی خفیہ رہنا چاہیے تو واحد معقول راستہ پرامپٹس اور فراہم کنندہ کالز کو اپنے سرور پر منتقل کرنا ہے، جو «اپنی کلید، بغیر بیک اینڈ» کے ڈیزائن کو ختم کر دیتا ہے۔

ریپوزٹری دیے بغیر تقسیم کے لیے zip کو Chrome Web Store پر **نجی یا غیر فہرست شدہ** آئٹم کے طور پر شائع کریں؛ غیر تکنیکی صارف کے لیے ایک کلک کی تنصیب کا یہی واحد راستہ ہے۔

## فراہم کنندہ کی ترتیب

ایکسٹینشن کا پاپ اپ ← **Options & settings**، یا `brave://extensions` ← Details ← Extension options۔

| فراہم کنندہ | اینڈ پوائنٹ | کلید | نوٹس |
|---|---|---|---|
| **Ollama** (مقامی) | `http://localhost:11434` | کوئی نہیں | مفت اور مکمل طور پر نجی۔ [ollama.com](https://ollama.com) سے نصب کریں، پھر `ollama run llama3` چلائیں۔ 403 آنے پر `OLLAMA_ORIGINS=chrome-extension://*` کے ساتھ دوبارہ چلائیں۔ |
| **Google Gemini** | `generativelanguage.googleapis.com` | [AI Studio](https://aistudio.google.com/app/apikey) سے مفت کلید | موجودہ ماڈل شناخت استعمال کریں، مثلاً `gemini-2.5-flash`۔ مفت حدود بدلتی ہیں؛ Google کی ماڈل فہرست دیکھیں۔ |
| **OpenAI سے ہم آہنگ** | آپ کا اینڈ پوائنٹ، مثلاً `https://openrouter.ai/api/v1`، `https://api.groq.com/openai/v1` یا `https://integrate.api.nvidia.com/v1` | فراہم کنندہ کی کلید | کوئی بھی سروس جو `/chat/completions` سمجھتی ہو۔ انٹرفیس میں تجویز کردہ ماڈل صرف مثالیں ہیں؛ فراہم کنندہ کے کیٹلاگ سے درست شناخت لیں۔ |

پھر:

1. **ڈیفالٹ ہدف زبان** منتخب کریں۔
2. **ترجمے کا انداز** منتخب کریں: *Natural* (تجویز کردہ) یا *Literal*۔
3. چاہیں تو **Quality mode** آن کریں اور **لغت** بھریں (فی سطر ایک اندراج: `اصطلاح ← ترجمہ`؛ `->`، `=>`، `=` اور TAB بھی چلتے ہیں)۔
4. **ماخذ زبان** کو *Auto-detect* پر رکھیں یا خود منتخب کریں۔
5. **Test connection** اور پھر **Save settings** پر کلک کریں۔

فراہم کنندہ سے متعلق نوٹس:

- **Gemini کی سوچ کی ترتیب ماڈل کی نسل کے مطابق چنی جاتی ہے۔** 2.5 Flash اور Flash-Lite سوچ بند کر کے چلتے ہیں، 2.5 Pro کم از کم بجٹ (128) استعمال کرتا ہے، اور 3.x/4.x سوچ کی نچلی سطح۔ اگر ماڈل یہ ترتیب مسترد کرے تو درخواست ایک بار اس کے بغیر دہرائی جاتی ہے۔
- **Ollama** کو 8192 ٹوکن کے سیاق و سباق کے ساتھ کال کیا جاتا ہے؛ کم سیاق پر تربیت یافتہ ماڈل لمبے صفحات پھر بھی کاٹے گا — اسی لیے صفحہ چھوٹی اکائیوں میں تقسیم ہوتا ہے۔
- **مفت منصوبے** رفتار محدود کرتے ہیں۔ ایکسٹینشن انتظار کر کے دوبارہ کوشش کرتا ہے؛ متن خاموشی سے ضائع نہیں کرتا۔

- کی بورڈ: `Ctrl+Shift+Y` (macOS پر `Cmd+Shift+Y`) ترجمہ آن/آف کرتا ہے؛ براؤزر کے شارٹ کٹ صفحے سے بدلا جا سکتا ہے۔
- **Auto-translate** آن ہو اور سائٹ کی ترجیح محفوظ ہو تو متعلقہ صفحات لوڈ پر خودکار ترجمہ ہو جاتے ہیں۔
- ترتیبات کھلے ٹیبز پر اگلے ترجمے سے لاگو ہوتی ہیں؛ دوبارہ لوڈ کرنے کی ضرورت نہیں۔

## یہ کیسے کام کرتا ہے

```
صفحے کا DOM
  └─ content script: بلاک اکائیاں جمع کرنا، اندرونی مارک اپ کو <tN>/<vN/> ٹوکن میں بدلنا
       └─ تقسیم کنندہ: فی درخواست 24 اکائیاں یا 2400 حروف
            └─ service worker: آپ کے فراہم کنندہ کو درخواست (ایکسٹینشن اصل، بغیر CORS)
                 └─ فراہم کنندہ: JSON اندر، JSON باہر، شناختیں محفوظ
                      └─ توثیق: ٹوکن مکمل، متوازن اور منفرد؛ شناختیں مطابق
                           └─ DOM: اصل نوڈز کا دوبارہ استعمال، صرف متن لکھنا
                                └─ MutationObserver: بعد میں شامل مواد کا ترجمہ
```

فیصلے جو واقعی فرق ڈالتے ہیں:

- **فراہم کنندہ کی ٹریفک کبھی صفحے کے سیاق سے باہر نہیں جاتی۔** content script `AIPT_FETCH` پیغام بھیجتا ہے؛ service worker درخواست کرتا ہے، اس لیے سخت CORS والے اینڈ پوائنٹس بھی ویسے ہی کام کرتے ہیں۔ service worker `sender.id` بھی جانچتا ہے، تاکہ صرف یہی ایکسٹینشن اسے پراکسی کے طور پر استعمال کر سکے۔
- **پرامپٹ ایک معاہدہ ہے، خواہش نہیں۔** شناختیں اندر، شناختیں باہر؛ ہر قطعے کے لیے ایک اندراج؛ ٹیگز اچھوت؛ اعداد، یو آر ایل، کوڈ اور placeholder جوں کے توں؛ کوئی اضافی وضاحت نہیں۔ جوابات شناخت کے مطابق پڑھے جاتے ہیں، اس لیے بدلی ہوئی یا ناقص صف ترجموں کو بے ترتیب کرنے کے بجائے محفوظ طریقے سے ناکام ہوتی ہے۔
- **ہر زبان کا اپنا اندازِ بیان ہے۔** اردو/فارسی رہنمائی مقامی الفاظ کی ترتیب اور فعل مانگتی ہے، `می‌باشد`/`بایستی`/`گردید` کو جہاں عام جملہ کافی ہو منع کرتی ہے، صرف حقیقی مستعار الفاظ لاطینی رسم الخط میں رکھتی ہے اور رموزِ اوقاف درست کرتی ہے۔ few-shot مثالیں ماڈل کو ہدف دکھاتی ہیں، صرف بیان نہیں کرتیں۔
- **سمت مقامی ہے۔** فارسی، عربی، عبرانی اور اردو بلاکس `dir="rtl"` لیتے ہیں، `<html>` ہدف زبان لیتا ہے اور باقی صفحہ اپنی جیومیٹری رکھتا ہے — پورا صفحہ پلٹنے سے درمیان میں رکھی ترتیبیں اور کوڈ بلاکس ٹوٹتے تھے۔ دونوں اصل متن کے ساتھ بحال ہوتے ہیں۔
- **ناکامیوں کی اطلاع ملتی ہے اور وہ محدود رہتی ہیں۔** جو قطعہ پڑھا نہ جا سکے وہ تقسیم ہوتا ہے؛ جو اکائی پھر بھی ناکام ہو وہ ماخذ زبان میں رہتی ہے اور اوپر کی پٹی میں بتائی جاتی ہے۔ ترجمے کے دوران منسوخی صاف رکتی ہے اور آدھا لکھا DOM نہیں چھوڑتی۔

مزید تفصیل: [`docs/translation-quality-design.md`](../translation-quality-design.md)۔

## رازداری اور اجازتیں

| اجازت | کیوں ضروری ہے |
|---|---|
| `storage` | ترتیبات، API کلید، لغت اور فی سائٹ ترجیحات `chrome.storage.local` میں محفوظ کرنا۔ |
| `contextMenus` | دائیں کلک کا «اس صفحے / انتخاب کا ترجمہ»۔ |
| `tabs` | فعال ٹیب کو پیغام بھیجنا اور Options کھولنا۔ |
| `activeTab` | اس صفحے پر کام کرنا جس کا ترجمہ آپ خود کرتے ہیں۔ |
| `<all_urls>` | دیکھے گئے صفحات میں content script داخل کرنا، اور service worker کو فراہم کنندہ کے اینڈ پوائنٹ تک رسائی دینا۔ |

- API کلید صرف اسی براؤزر کے مقامی ذخیرے میں رہتی ہے اور صرف آپ کے منتخب فراہم کنندہ کو بھیجی جاتی ہے۔
- کوئی تجزیاتی ٹول نہیں، کوئی ٹیلی میٹری نہیں، کوئی ریموٹ کوڈ نہیں، ڈویلپر کے سرور سے کوئی رابطہ نہیں، کوئی اکاؤنٹ نہیں۔
- سارا متن `textContent` اور `createTextNode` سے لکھا جاتا ہے؛ پوری ایکسٹینشن میں `innerHTML`، `eval` یا `new Function` نہیں۔ ماڈل کا نتیجہ صفحے تک صرف متن کے طور پر پہنچ سکتا ہے، اور خصوصیات ایک مقررہ اجازت یافتہ فہرست تک محدود ہیں؛ `href`، `src` اور ایونٹ ہینڈلرز کبھی ماڈل کے نتیجے سے نہیں لکھے جاتے۔
- فی سائٹ ترجیحات service worker میں ایک ہی ترتیب وار لکھنے والا لکھتا ہے، اس لیے دو ٹیب ایک دوسرے کی تحریر مٹا نہیں سکتے۔
- خودکار زبان کی شناخت زیادہ سے زیادہ 600 حروف کا نمونہ اسی فراہم کنندہ کو بھیجتی ہے؛ ماخذ زبان خود منتخب کریں تو یہ درخواست بھی ختم ہو جاتی ہے۔

سیکیورٹی پالیسی اور کمزوری کی اطلاع کا طریقہ: [`SECURITY.md`](../../SECURITY.md)۔

## معروف حدود

- **ٹوکن توثیق دانستہ سخت ہے۔** جو ماڈل `<tN>` مسلسل خراب کرے وہ ان پیراگرافوں کو اصل زبان میں چھوڑ دے گا (اور بتا دے گا) بجائے اس کے کہ رابطہ گرا دے۔ ایسا ماڈل استعمال کریں جو منظم نتائج کی پابندی کرے؛ *Test connection* ٹوکن والا جملہ آزما کر دیکھتا ہے۔
- **معیار ماڈل پر منحصر ہے۔** چھوٹے مقامی ماڈل قابلِ استعمال ہیں مگر Gemini یا GPT درجے کے ماڈلز سے کم روان؛ انداز کی تہہ مدد کرتی ہے، علم نہیں بڑھاتی۔
- **بند شیڈو روٹس اور cross-origin iframes** ایکسٹینشن کی رسائی سے باہر ہیں (براؤزر سیکیورٹی)۔ کھلے شیڈو روٹس اور ہم اصل فریموں کی پشت پناہی ہوتی ہے۔
- **مخلوط کنٹینرز جن میں کھلا متن ہو** (`<div>متن<p>…</p></div>`) اسی کھلے متن کے لیے نوڈ بہ نوڈ ترجمے پر واپس جاتے ہیں؛ درست صفحات اس حالت تک نہیں پہنچتے۔
- **کیش میموری میں ہے** (اسی ٹیب کے سیشن تک)۔ صفحہ دوبارہ لوڈ کریں تو متن دوبارہ طلب ہوتا ہے۔
- **PDF کا ترجمہ نہیں ہوتا**؛ براؤزر کا بلٹ اِن PDF ویور ایکسٹینشنز کے لیے قابلِ اسکرپٹ نہیں۔
- **مفت منصوبے بدلتے ہیں۔** رفتار کی حدیں اور ماڈل نام فراہم کنندہ کے اختیار میں ہیں، اس ایکسٹینشن کے نہیں۔

## منصوبے کی حالت اور ٹیسٹ

ورژن 1.3.1۔ خودکار سوٹ DOM تہہ، پرامپٹ اور تجزیہ، فراہم کنندگان کی درخواست کی ساخت، انجن کا رویہ اور Options انٹرفیس کا احاطہ کرتا ہے — **95 ٹیسٹ** — اور `npm run verify` 12 نکاتی جانچ شامل کرتا ہے: نحو، ٹیسٹ سوٹ، HTML سنکس کی ممانعت، کلید کے اخراج کی جانچ، کلاسک content scripts، ورژن کی مطابقت، CHANGELOG کی پوشش اور پیکیجنگ۔

```bash
npm install       # صرف ترقی: DOM ٹیسٹ کے لیے jsdom
npm test          # 95 ٹیسٹ
npm run bench     # تقسیم کی پیمائش، بغیر API کلید
npm run verify    # نحو + ٹیسٹ + پالیسی جانچ + پیکیجنگ
npm run package   # صرف قابلِ ارسال فائلیں dist/ میں کاپی
npm run release   # dist اور release/*.zip، *.crx، *.pem تقسیم کے لیے
```

پیمائش تقسیم ناپتی ہے، ترجمے کا معیار نہیں: چار نمونہ صفحات پر ایک آزاد متن نوڈ جمع کرنے والا **108 ٹکڑے** بناتا ہے جبکہ بلاک جمع کرنے والا **63 اکائیاں** (مجموعی طور پر 1.7 گنا کم، خبر کے مضمون پر **2.5 گنا**)، اور 25 حروف سے چھوٹے ٹکڑے **81 سے 34** رہ جاتے ہیں۔ ترجمے کا معیار خود اس ماڈل پر منحصر ہے جو آپ جوڑتے ہیں؛ براؤزر سطح کا رویہ جو خودکار ٹیسٹ نہیں پکڑ سکتے (RTL نمائش، ٹول ٹپس، حقیقی SPA ٹریفک اور فراہم کنندہ کی غلطیاں) [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) میں درج ہیں۔

CI ہر push اور pull request پر `npm run verify` اور `npm run bench` کو Node 20 اور 22 پر چلاتا ہے ([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml))۔

## تعاون

مسائل اور pull requests کا خیر مقدم ہے۔ تبدیلی بھیجنے سے پہلے `npm run verify` چلائیں؛ ایکسٹینشن کو بغیر بلڈ مرحلے کے رکھیں، فراہم کنندہ کی ٹریفک service worker میں رکھیں اور کبھی `innerHTML` مت لائیں۔ اگر پرامپٹ بدلیں تو ٹیسٹ شامل یا بہتر کریں؛ پرامپٹ، تجزیہ کار اور نارملائزر ایک ساتھ جانچے جاتے ہیں کیونکہ وہ صرف ایک مجموعے کے طور پر کام کرتے ہیں۔

مکمل قواعد، `docs/i18n/` کی ترجمہ پالیسی اور commit کے اصول [`CONTRIBUTING.md`](../../CONTRIBUTING.md) میں پڑھیں۔
