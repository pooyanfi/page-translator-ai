# AI Page Translator — ترجمهٔ صفحه‌های وب با هوش مصنوعی خودتان

**هر صفحهٔ وب را با ارائه‌دهندهٔ هوش مصنوعی خودتان به زبان خودتان ترجمه کنید — بدون سرور واسط، بدون حساب کاربری، بدون ردیابی و بدون پرداخت به‌ازای هر واژه.**

AI Page Translator یک افزونهٔ مرورگر برای **Brave** و دیگر مرورگرهای مبتنی بر Chromium است. ارائه‌دهنده را خودتان انتخاب می‌کنید: کلید رایگان Google Gemini، هر نقطهٔ پایانی سازگار با OpenAI (OpenRouter، Groq، NVIDIA، OpenAI و مانند این‌ها)، یا مدلی کاملاً محلی با **Ollama**. افزونه صفحه‌ای را که می‌خوانید در همان‌جا ترجمه می‌کند و چیدمان، پیوندها و قالب‌بندی آن را حفظ می‌کند.

هیچ متنی از سرویس ترجمهٔ واسطی عبور نمی‌کند. کلید API از مرورگر شما خارج نمی‌شود، هیچ ابزار تحلیلی در کار نیست و اگر Ollama را انتخاب کنید، متن حتی از رایانهٔ شما بیرون نمی‌رود.

> **وضعیت:** نسخهٔ 1.3.1 · ۹۵ آزمون خودکار · بازبینی ۱۲ نقطه‌ای · بدون تله‌متری، بدون کد راه‌دور.

## چرا یک مترجم دیگر؟

بیشتر مترجم‌های صفحه، جمله‌به‌جمله ترجمه می‌کنند. نتیجه همان چیزی است که دیده‌اید: جمله‌هایی پشت‌سرهم و بی‌ارتباط با هم، اصطلاحاتی که از ابتدا تا انتهای صفحه یکدست نمی‌مانند و جمله‌هایی که ترتیب واژه‌های زبان مبدأ را به ارث برده‌اند. بدتر از همه، پیوندی که میان جمله می‌آید آن را به دو نیم می‌کند.

این افزونه به‌جای گره‌های متنی، **بلوک‌ها** را ترجمه می‌کند:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

این بلوک به‌صورت یک واحد فرستاده می‌شود و نشانه‌گذاری درون‌خطی جای خود را به توکن شماره‌دار می‌دهد:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` محتوای درون‌خطی متعلق به جمله را نشان می‌دهد (پیوند، تأکید، span) و `<vN/>` محتوایی را که هرگز نباید ترجمه شود (کد، تصویر، کنترل فرم، ویجت). مدل اجازه دارد توکن‌ها را جابه‌جا کند؛ بنابراین می‌تواند جملهٔ طبیعی زبان مقصد را **حول پیوند** بسازد، نه اینکه به ترتیب انگلیسی محدود بماند.

پاسخ پیش از اعمال روی صفحه اعتبارسنجی می‌شود: هر توکن باید حاضر، متوازن و یکتا باشد. ترجمه‌ای که پیوندی را حذف کند رد می‌شود، یک بار با دستور سخت‌گیرانه‌تری تکرار می‌شود و اگر باز هم درست نشود، آن بخش دست‌نخورده می‌ماند. گره‌های اصلی صفحه دوباره استفاده می‌شوند، بنابراین `href`، شنونده‌های رویداد و نشانه‌گذاری تو‌در‌تو سالم می‌مانند. گزینهٔ «نمایش متن اصلی» هم دقیقاً همان گره‌های اولیه را بازمی‌گرداند.

## امکانات

- **ترجمهٔ کامل صفحه در همان‌جا** — عنوان‌ها، پاراگراف‌ها، فهرست‌ها، جدول‌ها، زیرنویس تصویرها و دکمه‌ها.
- **حفظ پیوندها و قالب‌بندی درون‌خطی** — با اعتبارسنجی توکن؛ پیوندِ حذف‌شده هرگز بی‌صدا اعمال نمی‌شود.
- **سبک طبیعی یا تحت‌اللفظی** — «طبیعی» (پیش‌فرض) مانند نویسنده‌ای بومی بازنویسی می‌کند؛ «تحت‌اللفظی» برای صفحه‌های فنی به متن مبدأ نزدیک می‌ماند.
- **راهنمای سبک برای هر زبان** — راهنمای اختصاصی برای فارسی، عربی، اردو و عبری و یک راهنمای عمومی برای ۱۸ زبان دیگر.
- **اصلاح قطعی رسم‌الخط** — «ی» و «ک» فارسی، نیم‌فاصله در «می»، «ها» و «تر» و نشانه‌های «، ؛ ؟» حتی وقتی مدل اشتباه کند اصلاح می‌شوند.
- **بازبینی کیفیت (اختیاری)** — هر قطعه را به‌صورت جفت «مبدأ و ترجمه» بررسی می‌کند تا خطای معنایی را هم اصلاح کند، نه فقط ظاهر جمله را.
- **واژه‌نامه** — جفت‌های «واژه ← ترجمه» که مدل باید دقیقاً رعایت کند.
- **محتوای محافظت‌شده** — `<pre>`، `<code>`، نشانی‌ها، ایمیل‌ها، `translate="no"`، `contenteditable`، SVG، کنترل‌های فرم و رابط خود افزونه هرگز ارسال نمی‌شوند.
- **ترجمهٔ برچسب‌ها** — `alt`، `title`، `placeholder` و `aria-label` در کانالی جداگانه و با لحن برچسب ترجمه می‌شوند، نه مانند پاراگراف.
- **صفحه‌های پویا** — محتوای تازه در اسکرول بی‌پایان یا برنامه‌های تک‌صفحه‌ای (SPA) به‌محض ظاهر شدن ترجمه می‌شود، بدون حلقهٔ بی‌پایان ناظر DOM.
- **راست‌به‌چپ درست** — `dir` روی هر بلوک ترجمه‌شده، `lang` روی `<html>` و بدون چرخاندن کل صفحه؛ همه‌چیز بازگردانی می‌شود.
- **حافظهٔ هر سایت** — زبان مقصد هر دامنه را به یاد می‌آورد و در صورت فعال بودن، هنگام بارگذاری خودکار ترجمه می‌کند.
- **هر سرویسی که API دارد** — Gemini، Ollama و هر نقطهٔ پایانی سازگار با OpenAI، از طریق service worker و بدون دردسر CORS.
- **حافظهٔ موقت، تلاش دوباره و تقسیم خودکار** — متن یکسان فقط یک بار ارسال می‌شود؛ قطعهٔ ناموفق تقسیم می‌شود، نه اینکه کل صفحه شکست بخورد؛ خطاهای 429 و 5xx با تأخیر فزاینده تکرار می‌شوند.
- **بدون مرحلهٔ ساخت** — اسکریپت‌های کلاسیک ساده، همان‌طور که هستند بارگذاری می‌شوند.

## نصب

۱. این مخزن را دانلود کنید (**Code → Download ZIP** یا `git clone`) و پوشه را نگه دارید.
۲. `brave://extensions` (یا `chrome://extensions`) را باز کنید.
۳. گزینهٔ **Developer mode** را روشن کنید.
۴. روی **Load unpacked** بزنید و همین پوشه را انتخاب کنید؛ همان جایی که `manifest.json` دارد.
۵. اگر می‌خواهید پاپ‌آپ با یک کلیک در دسترس باشد، افزونه را Pin کنید.

هیچ مرحلهٔ ساخت، نصب یا بسته‌بندی وجود ندارد. افزونه فقط فایل‌هایی را می‌خواند که در `manifest.json` آمده‌اند؛ پوشه‌های `tests/`، `scripts/`، `bench/`، `docs/` و `.github/` فقط برای توسعه‌اند و هرگز بارگذاری نمی‌شوند.

به مرورگر نسبتاً تازه‌ای مبتنی بر Chromium نیاز دارید. شادو روت‌های بسته (closed shadow root) در مرورگرهایی ترجمه می‌شوند که API آن را در اختیار بگذارند (Chromium 119 و بالاتر)؛ بقیهٔ امکانات در نسخه‌های قدیمی‌تر هم کار می‌کنند.

## اشتراک‌گذاری با دیگران

دستور `npm run release` بسته را می‌سازد و فایل‌های خروجی را در پوشهٔ `release/` می‌گذارد (این پوشه در Git نیست):

| فایل | چیست | روش نصب |
|---|---|---|
| `page-translator-ai-<version>.zip` | کل افزونه، حدود ۹۵ کیلوبایت، همراه با `INSTALL.txt` در داخل آن | از حالت فشرده درآورد و **Load unpacked** بزند؛ همان فایلی که فروشگاه هم می‌پذیرد |
| `page-translator-ai-<version>.crx` | بستهٔ امضاشده | روی `brave://extensions` بکشد؛ جایی که نصب بیرون از فروشگاه مجاز است |
| `page-translator-ai-signing-key.pem` | کلید امضا | آن را به کسی ندهید؛ `npm run release` از همان کلید استفاده می‌کند تا شناسهٔ افزونه در به‌روزرسانی‌ها ثابت بماند |

یعنی چیزی که به دست دیگران می‌دهید یک فایل است و راهنمای نصب هم داخل آن است.

**یک محدودیت صادقانه:** افزونهٔ مرورگر کد سمت کاربر است. هر کسی آن را نصب کند می‌تواند همان فایل‌ها را بخواند — `.crx` یک فایل zip امضاشده است و افزونهٔ بارگذاری‌شده یک پوشهٔ معمولی. هیچ بسته‌بندی یا مبهم‌سازی‌ای این واقعیت را تغییر نمی‌دهد؛ مبهم‌سازی فقط خواندن را کند می‌کند و سیاست فروشگاه هم آن را ممنوع می‌داند. اگر واقعاً باید کد مخفی بماند، تنها راه منطقی انتقال پرامپت‌ها و تماس با ارائه‌دهنده به سروری است که خودتان کنترل می‌کنید؛ که یعنی کنار گذاشتن طراحی «کلید خودتان، بدون سرور واسط».

برای توزیع بدون دادن مخزن کد، zip را به‌صورت آیتم **خصوصی یا unlisted** در Chrome Web Store منتشر کنید؛ برای کاربر غیرفنی، تنها راه نصب یک‌کلیکی همین است.

## تنظیم ارائه‌دهنده

پاپ‌آپ افزونه ← **Options & settings**، یا `brave://extensions` ← Details ← Extension options.

| ارائه‌دهنده | نقطهٔ پایانی | کلید | توضیح |
|---|---|---|---|
| **Ollama** (محلی) | `http://localhost:11434` | ندارد | رایگان و کاملاً خصوصی. از [ollama.com](https://ollama.com) نصب کنید و بعد `ollama run llama3` را اجرا کنید. اگر Ollama خطای 403 برگرداند، آن را با `OLLAMA_ORIGINS=chrome-extension://*` دوباره راه‌اندازی کنید. |
| **Google Gemini** | `generativelanguage.googleapis.com` | کلید رایگان از [AI Studio](https://aistudio.google.com/app/apikey) | از شناسهٔ مدل روز استفاده کنید، مثل `gemini-2.5-flash`. سهمیهٔ رایگان تغییر می‌کند؛ فهرست مدل‌های گوگل را ببینید. |
| **سازگار با OpenAI** | نقطهٔ پایانی خودتان، مثل `https://openrouter.ai/api/v1`، `https://api.groq.com/openai/v1` یا `https://integrate.api.nvidia.com/v1` | کلید همان سرویس | هر نقطه‌ای که `/chat/completions` را پشتیبانی می‌کند. مدل‌های پیشنهادی در رابط فقط نمونه‌اند؛ شناسهٔ دقیق را از فهرست خود ارائه‌دهنده بردارید. |

سپس:

۱. **زبان مقصد پیش‌فرض** را انتخاب کنید.
۲. **سبک ترجمه** را انتخاب کنید: *Natural* (پیشنهادی) یا *Literal*.
۳. اگر خواستید **Quality mode** را روشن کنید و **واژه‌نامه** را پر کنید (هر خط یک مورد: `واژه ← ترجمه`؛ `->`، `=>`، `=` و TAB هم پذیرفته می‌شوند).
۴. **زبان مبدأ** را روی *Auto-detect* بگذارید یا خودتان انتخاب کنید.
۵. **Test connection** و بعد **Save settings** را بزنید.

نکته‌های ارائه‌دهنده:

- **تنظیم فکر Gemini بر اساس نسل مدل انتخاب می‌شود.** 2.5 Flash و Flash-Lite با فکر خاموش کار می‌کنند، 2.5 Pro از کمینهٔ مجاز (۱۲۸) استفاده می‌کند و 3.x و 4.x سطح فکر پایین دارند. اگر مدلی این تنظیم را نپذیرد، درخواست یک بار بدون آن تکرار می‌شود.
- **Ollama** با پنجرهٔ بافت ۸۱۹۲ توکن فراخوانی می‌شود؛ مدلی که با بافت کمتری آموزش دیده باشد باز هم صفحه‌های بلند را کوتاه می‌کند — به همین دلیل صفحه به قطعه‌های کوچک تقسیم می‌شود.
- **سهمیه‌های رایگان** محدودند. افزونه کمی صبر می‌کند و دوباره تلاش می‌کند؛ متن را بی‌صدا حذف نمی‌کند.

## استفاده

- روی آیکون بزنید ← زبان را انتخاب کنید ← **Translate this page**.
- **Show original / Show translation** هر زمان که بخواهید؛ بازگردانی بدون افت است.
- نشانگر را روی پاراگراف ترجمه‌شده ببرید تا متن اصلی را ببینید.
- راست‌کلیک ← **Translate this page** یا **Translate selection**.
- میانبر: `Ctrl+Shift+Y` (در macOS: `Cmd+Shift+Y`) ترجمه را روشن و خاموش می‌کند؛ از صفحهٔ میانبرهای مرورگر می‌توانید تغییرش دهید.
- اگر **Auto-translate** روشن باشد و برای دامنه تنظیمی ذخیره شده باشد، صفحه هنگام بارگذاری خودکار ترجمه می‌شود.
- تنظیمات روی تب‌های باز، از ترجمهٔ بعدی اعمال می‌شوند؛ نیازی به بارگذاری دوبارهٔ صفحه نیست.

## نحوهٔ کار

```
DOM صفحه
  └─ content script: جمع‌آوری واحدهای بلوکی، تبدیل نشانه‌گذاری درون‌خطی به توکن <tN>/<vN/>
       └─ تقسیم‌کننده: ۲۴ واحد یا ۲۴۰۰ کاراکتر در هر درخواست
            └─ service worker: ارسال درخواست به ارائه‌دهندهٔ شما (مبدأ افزونه، بدون CORS)
                 └─ ارائه‌دهنده: JSON می‌گیرد، JSON می‌دهد، شناسه‌ها حفظ می‌شوند
                      └─ اعتبارسنجی: کامل، متوازن و یکتا بودن توکن‌ها و تطابق شناسه‌ها
                           └─ DOM: استفادهٔ دوباره از گره‌های اصلی، نوشتن فقط متن
                                └─ MutationObserver: ترجمهٔ محتوای تازه‌اضافه‌شده
```

تصمیم‌هایی که واقعاً تفاوت می‌سازند:

- **درخواست‌ها هرگز از بافت صفحه بیرون نمی‌روند.** content script پیام `AIPT_FETCH` می‌فرستد و service worker درخواست را انجام می‌دهد؛ بنابراین نقطهٔ پایانی با CORS سخت‌گیرانه هم بدون تغییر کار می‌کند. service worker مقدار `sender.id` را بررسی می‌کند تا فقط همین افزونه بتواند از آن به‌عنوان واسط استفاده کند.
- **پرامپت یک قرارداد است، نه یک آرزو.** شناسه می‌گیرد و شناسه پس می‌دهد؛ برای هر قطعه یک ورودی؛ توکن‌ها دست‌نزدنی؛ اعداد، نشانی‌ها، کد و placeholder بدون تغییر؛ بدون توضیح اضافه. پاسخ بر اساس شناسه تجزیه می‌شود، بنابراین آرایهٔ جابه‌جاشده یا ناقص به‌جای جابه‌جا کردن ترجمه‌ها، بی‌خطر شکست می‌خورد.
- **هر زبان راهنمای سبک خودش را دارد.** راهنمای فارسی مثلاً ترتیب واژه و فعل فارسی می‌خواهد (`بررسی کنید`، نه `بررسی را انجام دهید`)، `می‌باشد` و `بایستی` و `گردید` را جایی که یک جملهٔ معمولی کافی است ممنوع می‌کند، فقط وام‌واژه‌های واقعی را لاتین نگه می‌دارد و علائم و نیم‌فاصله را درست می‌کند. مثال‌های few-shot هدف را به مدل نشان می‌دهند، نه اینکه فقط توصیفش کنند.
- **جهت، محلی است.** بلوک‌های فارسی، عربی، عبری و اردو `dir="rtl"` می‌گیرند، `<html>` زبان مقصد را می‌گیرد و بقیهٔ صفحه هندسهٔ خودش را نگه می‌دارد؛ چرخاندن کل صفحه چیدمان‌های وسط‌چین و بلوک‌های کد را خراب می‌کرد. هر دو همراه متن اصلی بازگردانی می‌شوند.
- **خطاها دیده می‌شوند و محدود می‌مانند.** قطعه‌ای که تجزیه نمی‌شود نصف می‌شود؛ واحدی که باز هم شکست بخورد به زبان اصلی می‌ماند و در نوار بالای صفحه گزارش می‌شود. لغو در میانهٔ ترجمه، تمیز متوقف می‌شود و DOM نیمه‌نوشته باقی نمی‌گذارد.

جزئیات بیشتر: [`docs/translation-quality-design.md`](../translation-quality-design.md).

## حریم خصوصی و مجوزها

| مجوز | چرا لازم است |
|---|---|
| `storage` | ذخیرهٔ تنظیمات، کلید API، واژه‌نامه و تنظیمات هر سایت در `chrome.storage.local`. |
| `contextMenus` | گزینهٔ راست‌کلیک «ترجمهٔ این صفحه / انتخاب». |
| `tabs` | ارسال پیام به تب فعال و باز کردن Options. |
| `activeTab` | کار روی صفحه‌ای که خودتان ترجمه می‌کنید. |
| `<all_urls>` | تزریق content script در صفحه‌هایی که می‌بینید و اجازهٔ تماس service worker با نقطهٔ پایانی ارائه‌دهنده. |

- کلید API فقط در حافظهٔ محلی همین مرورگر ذخیره می‌شود و فقط به ارائه‌دهنده‌ای می‌رود که خودتان انتخاب کرده‌اید.
- بدون ابزار تحلیلی، بدون تله‌متری، بدون کد راه‌دور، بدون تماس با سرور سازنده و بدون حساب کاربری.
- همهٔ متن‌ها با `textContent` و `createTextNode` نوشته می‌شوند؛ در سراسر افزونه هیچ `innerHTML`، `eval` یا `new Function` وجود ندارد. خروجی مدل فقط به‌صورت متن به صفحه می‌رسد و ویژگی‌ها به یک فهرست مجاز ثابت محدودند؛ `href`، `src` و شنونده‌های رویداد هرگز از خروجی مدل نوشته نمی‌شوند.
- تنظیمات هر سایت را یک نویسندهٔ سریال‌شده در service worker می‌نویسد؛ بنابراین دو تب نمی‌توانند نوشتهٔ یکدیگر را از بین ببرند.
- تشخیص خودکار زبان حداکثر ۶۰۰ کاراکتر نمونه را به همان ارائه‌دهنده می‌فرستد؛ اگر زبان مبدأ را دستی انتخاب کنید، این درخواست هم حذف می‌شود.

سیاست امنیتی و روش گزارش آسیب‌پذیری: [`SECURITY.md`](../../SECURITY.md).

## محدودیت‌های شناخته‌شده

- **اعتبارسنجی توکن عمداً سخت‌گیر است.** مدلی که مرتب `<tN>` را خراب کند، آن پاراگراف‌ها را به زبان اصلی می‌گذارد (و اعلام می‌کند) تا اینکه پیوندی را حذف کند. از مدلی استفاده کنید که خروجی ساخت‌یافته را رعایت می‌کند؛ *Test connection* یک جملهٔ توکن‌دار را می‌آزماید.
- **کیفیت به مدل بستگی دارد.** مدل‌های کوچک محلی قابل استفاده‌اند اما از Gemini یا مدل‌های کلاس GPT روان‌تر نیستند؛ لایهٔ سبک کمک می‌کند، ولی دانشی به مدل اضافه نمی‌کند.
- **شادو روت‌های بسته و iframeهای cross-origin** از دسترس افزونه خارج‌اند (امنیت مرورگر). شادو روت‌های باز و قاب‌های هم‌مبدأ پوشش داده می‌شوند.
- **ظرف‌های ترکیبی با متن پراکنده** (`<div>متن<p>…</p></div>`) برای همان متن پراکنده به روش قدیمیِ گره‌به‌گره برمی‌گردند؛ صفحه‌های استاندارد هرگز به این حالت نمی‌رسند.
- **حافظهٔ موقت در RAM است** (در طول نشست همان تب). با بارگذاری دوبارهٔ صفحه، متن دوباره درخواست می‌شود.
- **PDF ترجمه نمی‌شود**؛ نمایشگر داخلی PDF در دسترس افزونه‌ها نیست.
- **سهمیه‌های رایگان تغییر می‌کنند.** محدودیت نرخ و نام مدل‌ها در اختیار ارائه‌دهنده است، نه این افزونه.

## وضعیت پروژه و آزمون‌ها

نسخهٔ 1.3.1. مجموعهٔ خودکار، لایهٔ DOM، پرامپت و تجزیه، شکل درخواست‌های ارائه‌دهنده، رفتار موتور و رابط Options را پوشش می‌دهد — **۹۵ آزمون** — و `npm run verify` یک بازبینی ۱۲ نقطه‌ای به آن اضافه می‌کند: بررسی نحو، اجرای آزمون‌ها، ممنوعیت sinkهای HTML، بررسی نشت کلید، کلاسیک بودن content scriptها، هم‌خوانی نسخه‌ها، پوشش CHANGELOG و بسته‌بندی.

```bash
npm install       # فقط توسعه: jsdom برای آزمون‌های DOM
npm test          # ۹۵ آزمون
npm run bench     # سنجش قطعه‌بندی، بدون نیاز به کلید API
npm run verify    # نحو + آزمون‌ها + بررسی‌های سیاستی + کنترل بسته‌بندی
npm run package   # کپی فقط فایل‌های قابل ارسال در dist/
npm run release   # dist به‌همراه release/*.zip، *.crx و *.pem برای توزیع
```

سنجش، «قطعه‌بندی» را اندازه می‌گیرد نه کیفیت ترجمه: روی چهار صفحهٔ نمونه، جمع‌آور مستقل گره‌های متنی **۱۰۸ قطعه** می‌سازد و جمع‌آور بلوکی **۶۳ واحد** (۱٫۷ برابر کمتر، **۲٫۵ برابر** روی مقالهٔ خبری) و قطعه‌های کوتاه‌تر از ۲۵ کاراکتر از **۸۱ به ۳۴** کاهش می‌یابند. کیفیت خود ترجمه به مدلی بستگی دارد که وصل می‌کنید؛ رفتار سطح مرورگر که آزمون خودکار به آن نمی‌رسد (نمایش راست‌به‌چپ، تولتیپ، ترافیک واقعی SPA و خطاهای ارائه‌دهنده) در [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) آمده است.

CI در هر push و pull request دستورهای `npm run verify` و `npm run bench` را روی Node 20 و 22 اجرا می‌کند ([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).

## مشارکت

اگر باگی دیدید یا تغییری پیشنهاد دارید، issue یا pull request بفرستید. پیش از ارسال تغییر، `npm run verify` را اجرا کنید؛ افزونه را بدون مرحلهٔ ساخت نگه دارید، درخواست‌های ارائه‌دهنده را در service worker بگذارید و هرگز `innerHTML` به کار نبرید. اگر پرامپت را عوض کردید، آزمون اضافه یا به‌روز کنید؛ پرامپت، تجزیه‌گر و نرمال‌ساز با هم آزموده می‌شوند، چون فقط به‌صورت یک مجموعه کار می‌کنند.

قواعد کامل، سیاست ترجمهٔ `docs/i18n/` و قرارداد پیام‌های commit در [`CONTRIBUTING.md`](../../CONTRIBUTING.md) آمده است.
