AI Page Translator הוא תוסף דפדפן ל־**Brave** ולשאר הדפדפנים המבוססים על Chromium. אתם מביאים את הספק: מפתח Google Gemini חינמי, כל נקודת קצה תואמת OpenAI (OpenRouter, Groq, NVIDIA, OpenAI…), או מודל מקומי לחלוטין דרך **Ollama**. התוסף מתרגם את העמוד שאתם קוראים במקומו, ושומר על הפריסה, הקישורים והעיצוב.

שום טקסט לא עובר דרך שירות תרגום מתווך. מפתח ה-API לא יוצא מהדפדפן, אין שום כלי אנליטיקה, ועם Ollama הטקסט אפילו לא יוצא מהמחשב.

> **מצב:** גרסה 1.3.1 · 95 בדיקות אוטומטיות · בדיקה בת 12 נקודות · בלי טלמטריה ובלי קוד מרוחק.

## למה עוד מתרגם?

רוב מתרגמי העמודים שולחים משפט אחד בכל פעם. זו הסיבה שהתוצאה נראית כמו ערימה של משפטים ולא כמו עמוד: ההקשר הולך לאיבוד, המונחים משתנים, קישורים חותכים משפטים באמצע, ושפת היעד יורשת את סדר המילים של שפת המקור.

התוסף הזה מתרגם **בלוקים** ולא צמתי טקסט:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

הבלוק נשלח כיחידה אחת, והסימון המוטבע מוחלף באסימונים ממוספרים:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` מסמן תוכן מוטבע ששייך למשפט (קישור, הדגשה, span), ו־`<vN/>` מסמן תוכן שאסור לתרגם (קוד, תמונות, רכיבי טופס, וידג׳טים). המודל רשאי להזיז אסימונים, ולכן הוא בונה משפט טבעי **סביב** הקישור במקום להיות כבול לסדר האנגלי.

בחזרה, התשובה נבדקת לפני שנוגעים בעמוד. כל אסימון חייב להיות נוכח, מאוזן וייחודי; תרגום שמשמיט קישור נדחה, מנוסה שוב פעם אחת עם הוראה מחמירה יותר, ואם עדיין אינו תקין — נשאר כפי שהוא. צמתי העמוד המקוריים נמצאים בשימוש חוזר, ולכן `href`, מאזיני אירועים וסימון מקונן נשארים שלמים. האפשרות „הצג מקור” מחזירה בדיוק את הצמתים המקוריים.

## תכונות

- **תרגום מלא של העמוד במקומו** — כותרות, פסקאות, רשימות, טבלאות, כיתובים וכפתורים.
- **קישורים ועיצוב מוטבע נשמרים** — באימות אסימונים; קישור שהושמט לעולם לא יחול בשקט.
- **סגנון טבעי או מילולי** — *טבעי* (ברירת מחדל) מנסח מחדש כמו כותב מקומי; *מילולי* נשאר קרוב לנוסח המקור בעמודים טכניים.
- **מדריכי סגנון לכל שפה** — הנחיות ייעודיות לפרסית, ערבית, אורדו ועברית, ומדריך כללי ל־18 השפות האחרות.
- **תיקון טיפוגרפי דטרמיניסטי** — `ی`/`ک` בפרסית, רווחים בלתי־מפרידים ב־`می`/`ها`/`تر`, וסימני `، ؛ ؟` מתוקנים גם כשהמודל טועה.
- **מעבר איכות אופציונלי** — קורא כל מקטע כזוג {מקור, תרגום}, ולכן מתקן משמעות ולא רק ניסוח.
- **מילון מונחים** — זוגות מונח → תרגום שהמודל חייב לכבד.
- **תוכן מוגן** — `<pre>`, `<code>`, כתובות, דוא״ל, `translate="no"`, `contenteditable`, SVG, רכיבי טופס וממשק התוסף עצמו לא נשלחים לעולם.
- **תוויות מאפיינים** — `alt`, `title`, `placeholder` ו־`aria-label` עוברים בערוץ נפרד ובטון של תווית, לא של פסקה.
- **עמודים דינמיים** — תוכן מגלילה אינסופית או מאפליקציית עמוד יחיד מתורגם עם הופעתו, בלי לולאות צפייה.
- **ימין־לשמאל כמו שצריך** — `dir` על כל בלוק מתורגם, `lang` על `<html>`, בלי היפוך של העמוד כולו; הכול משוחזר.
- **זיכרון לכל אתר** — זוכר את שפת היעד לכל דומיין ויכול לתרגם אוטומטית בטעינה.
- **כל שירות עם API** — Gemini, Ollama וכל נקודת קצה תואמת OpenAI, נקראים מה-service worker ולכן בלי בעיות CORS.
- **מטמון בזיכרון, ניסיון חוזר ופיצול** — טקסט זהה נשלח פעם אחת; מקטע שנכשל מפוצל במקום להכשיל את העמוד; שגיאות 429/5xx מנוסות שוב בהמתנה גדלה.
- **בלי שלב בנייה** — סקריפטים קלאסיים פשוטים, נטענים כפי שהם.

## התקנה

1. הורידו את המאגר (**Code → Download ZIP** או `git clone`) ושמרו את התיקייה.
2. פתחו `brave://extensions` (או `chrome://extensions`).
3. הפעילו **Developer mode**.
4. לחצו **Load unpacked** ובחרו את התיקייה הזו (זו שמכילה `manifest.json`).
5. הצמידו את התוסף לסרגל אם אתם רוצים גישה בלחיצה אחת.

אין שלב בנייה, התקנה או אריזה. התוסף קורא רק את הקבצים המופיעים ב־`manifest.json`; התיקיות `tests/`, `scripts/`, `bench/`, `docs/` ו־`.github/` מיועדות לפיתוח בלבד ולעולם לא נטענות.

נדרש דפדפן Chromium עדכני. שורשי צל סגורים (closed shadow root) מתורגמים בדפדפנים שחושפים את ה-API (Chromium 119 ואילך); כל השאר עובד גם בגרסאות ישנות יותר.

## שיתוף עם אחרים

הפקודה `npm run release` בונה את החבילה ומייצרת את הקבצים בתיקייה `release/` (שאינה נכנסת ל-git):

| קובץ | מה זה | איך מתקינים |
|---|---|---|
| `page-translator-ai-<version>.zip` | התוסף כולו, כ־95 קילובייט, עם `INSTALL.txt` בפנים | פותחים את ה-zip ובוחרים **Load unpacked**; זה גם הקובץ שחנות מקבלת |

| `page-translator-ai-signing-key.pem` | מפתח החתימה | אל תשתפו אותו; `npm run release` משתמש בו שוב כדי שמזהה התוסף יישאר קבוע בין עדכונים |

כלומר, מה שאתם מוסרים למישהו הוא קובץ אחד, ובתוכו גם הוראות ההתקנה.

**מגבלה כנה:** תוסף דפדפן הוא קוד בצד הלקוח. כל מי שמתקין אותו יכול לקרוא את הקבצים — `.crx` הוא zip חתום ותוסף לא ארוז הוא תיקייה רגילה. שום אריזה או ערפול לא משנים את זה; ערפול רק מאט את הקריאה, ומדיניות החנויות אוסרת אותו. אם הקוד עצמו חייב להישאר סודי, האפשרות הסבירה היחידה היא להעביר את הפרומפטים ואת הקריאות לספק לשרת שבשליטתכם — וזה מוותר על המודל של „המפתח שלכם, בלי שרת”.

כדי להפיץ בלי למסור את המאגר, פרסמו את ה-zip כפריט **פרטי או לא רשום** ב-Chrome Web Store; זו הדרך היחידה להתקנה בלחיצה אחת למשתמש לא טכני.

ואז:

1. בחרו **שפת יעד ברירת מחדל**.
2. בחרו **סגנון תרגום**: *Natural* (מומלץ) או *Literal*.
3. אפשר להפעיל **Quality mode** ולהוסיף ערכי **מילון**, שורה לכל ערך (`מונח ← תרגום`; גם `->`, `=>`, `=` ו-TAB עובדים).
4. השאירו את **שפת המקור** על *Auto-detect* או בחרו אותה במפורש.
5. לחצו **Test connection** ואז **Save settings**.

הערות ספק:

- **הגדרת החשיבה של Gemini נבחרת לפי דור המודל.** 2.5 Flash ו-Flash-Lite רצים בלי חשיבה, 2.5 Pro משתמש במינימום (128), ו-3.x/4.x ברמת חשיבה נמוכה. אם מודל דוחה את ההגדרה, הבקשה מנוסה פעם אחת בלעדיה.
- **Ollama** נקרא עם חלון הקשר של 8192 אסימונים; מודל שאומן על פחות עדיין יקצר עמודים ארוכים — ולכן העמוד מחולק ליחידות קטנות.
- **מסלולים חינמיים** מוגבלים בקצב. התוסף ממתין ומנסה שוב; הוא לא מוחק טקסט בשקט.

## שימוש

- לחצו על הסמל ← בחרו שפה ← **Translate this page**.
- **Show original / Show translation** בכל רגע; השחזור ללא אובדן.
- רחפו מעל פסקה מתורגמת כדי להציץ במקור.
- לחיצה ימנית ← **Translate this page** או **Translate selection**.
- מקלדת: `Ctrl+Shift+Y` (`Cmd+Shift+Y` ב-macOS) מחליף תרגום; אפשר לשנות בדף קיצורי הדפדפן.
- עם **Auto-translate** דולק והעדפת אתר שמורה, עמודים מתאימים מתורגמים בטעינה.
- ההגדרות חלות על לשוניות פתוחות בתרגום הבא; אין צורך ברענון.

## איך זה עובד

```
DOM של העמוד
  └─ content script: איסוף יחידות בלוק, המרת סימון מוטבע לאסימוני <tN>/<vN/>
       └─ מפצל: 24 יחידות או 2400 תווים לבקשה
            └─ service worker: שליחת בקשה לספק שלכם (מקור התוסף, בלי CORS)
                 └─ ספק: JSON נכנס, JSON יוצא, המזהים נשמרים
                      └─ אימות: אסימונים מלאים, מאוזנים וייחודיים; מזהים תואמים
                           └─ DOM: שימוש חוזר בצמתים המקוריים, כתיבת טקסט בלבד
                                └─ MutationObserver: תרגום תוכן שנוסף לאחר מכן
```

החלטות שממש משנות:

- **תעבורת הספק לא יוצאת מהקשר העמוד.** ה-content script שולח הודעת `AIPT_FETCH`; ה-service worker מבצע את הבקשה, ולכן נקודות קצה עם CORS נוקשה עובדות كما הן. ה-service worker בודק גם `sender.id`, כך שרק התוסף הזה יכול להשתמש בו כמתווך.
- **הפרומפט הוא חוזה, לא משאלה.** מזהים נכנסים, מזהים יוצאים; רשומה לכל מקטע; תגים לא נוגעים; מספרים, כתובות, קוד ו-placeholders כמו שהם; בלי הסברים נוספים. התשובות נקראות לפי מזהה, ולכן מערך מסודר מחדש או פגום חלקית נכשל בבטחה במקום להזיז תרגומים.
- **לכל שפה מדריך סגנון משלה.** מדריך הפרסית, למשל, דורש סדר מילים ופעלים פרסיים (`بررسی کنید`, לא `بررسی را انجام دهید`), אוסר `می‌باشد`/`بایستی`/`گردید` היכן שמשפט רגיל מספיק, משאיר באלפבית לטיני רק שאילות אמיתיות, ומתקן פיסוק ורווחים. דוגמאות few-shot מראות למודל את היעד ולא רק מתארות אותו.
- **הכיוון מקומי.** בלוקים בפרסית, ערבית, עברית ואורדו מקבלים `dir="rtl"`, ‏`<html>` מקבל את שפת היעד, ושאר העמוד שומר על הגיאומטריה שלו — היפוך גלובלי שבר פריסות ממורכזות ובלוקי קוד. שניהם משוחזרים עם הטקסט המקורי.
- **כשלים גלויים ומוגבלים.** מקטע שלא ניתן לפרסר מפוצל; יחידה שעדיין נכשלת נשארת בשפת המקור ומדווחת בפס העליון. ביטול באמצע תרגום עוצר נקי ולא משאיר DOM כתוב למחצה.

עוד פרטים: [`docs/translation-quality-design.md`](../translation-quality-design.md).

|---|---|
| `storage` | שמירת הגדרות, מפתח API, מילון והעדפות לכל אתר ב־`chrome.storage.local`. |
| `contextMenus` | פריט בתפריט הלחיצה הימנית: „תרגם את העמוד / את הבחירה”. |
| `tabs` | שליחת הודעות ללשונית הפעילה ופתיחת Options. |
| `activeTab` | פעולה על העמוד שאתם מתרגמים במפורש. |
| `<all_urls>` | הזרקת content script לעמודים שאתם מבקרים בהם, ומתן אפשרות ל-service worker לקרוא לנקודת הקצה שהגדרתם. |

- מפתח ה-API נשמר רק באחסון המקומי של הדפדפן הזה ונשלח רק לספק שבחרתם.
- בלי אנליטיקה, בלי טלמטרי, בלי קוד מרוחק, בלי פנייה לשרת המפתח ובלי חשבון.
- כל הטקסט נכתב עם `textContent` / `createTextNode`; אין בתוסף `innerHTML`, `eval` או `new Function`. פלט המודל יכול להגיע לעמוד רק כטקסט, והמאפיינים מוגבלים לרשימת היתר קבועה — `href`, `src` ומאזיני אירועים לעולם לא נכתבים מפלט המודל.
- העדפות לכל אתר נכתבות בידי כותב יחיד ומסודר ב-service worker, כך ששתי לשוניות לא דורסות זו את זו.
- זיהוי שפה אוטומטי שולח לכל היותר דגימה של 600 תווים לאותו ספק; בחירת שפת מקור ידנית מבטלת את הבקשה הזו לגמרי.

מדיניות אבטחה ודיווח על חולשה: [`SECURITY.md`](../../SECURITY.md).

## מגבלות ידועות

- **אימות האסימונים נוקשה בכוונה.** מודל שמקלקל `<tN>` באופן עקבי ישאיר את הפסקאות האלה בשפת המקור (ויודיע על כך) במקום להשמיט קישור. השתמשו במודל שמכבד פלט מובנה; *Test connection* בודק משפט עם אסימונים.
- **האיכות תלויה במודל.** מודלים מקומיים קטנים שמישים אך פחות רהוטים מ-Gemini או ממודלים בדרגת GPT; שכבת הסגנון עוזרת, אבל היא לא מוסיפה ידע.
- **שורשי צל סגורים ו־iframe cross-origin** מחוץ להשגת התוסף (אבטחת הדפדפן). שורשי צל פתוחים ומסגרות מאותו מקור מטופלים.
- **מכולות מעורבות עם טקסט חופשי** (`<div>טקסט<p>…</p></div>`) חוזרות לתרגום צומת־אחר־צומת עבור אותו טקסט; עמודים תקינים לא מגיעים למצב הזה.
- **המטמון בזיכרון** (לכל הפעלה של לשונית). טעינה מחדש של עמוד תבקש את הטקסט שוב.
- **PDF לא מתורגם**; מציג ה-PDF המובנה אינו נגיש לסקריפטים של תוספים.
- **מסלולים חינמיים משתנים.** מגבלות הקצב ושמות המודלים נקבעים בידי הספק, לא בידי התוסף.

## מצב הפרויקט והבדיקות

גרסה 1.3.1. החבילה האוטומטית מכסה את שכבת ה-DOM, את הפרומפט והפענוח, את צורת הבקשות לספקים, את התנהגות המנוע ואת ממשק Options — **95 בדיקות** — ו־`npm run verify` מוסיף בדיקה בת 12 נקודות: תחביר, חבילת הבדיקות, איסור כיורי HTML, בדיקת דליפת מפתח, סקריפטים קלאסיים, התאמת גרסאות, כיסוי CHANGELOG ואריזה.

```bash
npm install       # פיתוח בלבד: jsdom לבדיקות ה-DOM
npm test          # 95 בדיקות
npm run bench     # מדידת חלוקה, בלי צורך במפתח API
npm run verify    # תחביר + בדיקות + בדיקות מדיניות + אריזה
npm run package   # העתקת הקבצים הניתנים לשליחה בלבד אל dist/
npm run release   # dist עם release/*.zip, *.crx, *.pem להפצה
```

המדידה מודדת חלוקה, לא איכות תרגום: בארבעה עמודי הדוגמה, אספן עצמאי של צמתי טקסט מייצר **108 שברים** בעוד אספן הבלוקים מייצר **63 יחידות** (פי 1.7 פחות בסך הכול, **פי 2.5** בכתבה החדשותית), ושברים באורך מתחת ל-25 תווים יורדים מ־**81 ל-34**. איכות התרגום עצמו עדיין תלויה במודל שאתם מחברים — הרשימה הידנית ב־[`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) מכסה את ההתנהגות ברמת הדפדפן שבדיקות אוטומטיות לא מגיעות אליה (תצוגת RTL, תלבשות, תעבורת SPA אמיתית ושגיאות ספק).

ה-CI מריץ `npm run verify` ו־`npm run bench` על Node 20 ו-22 בכל push וב־pull request ([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).
