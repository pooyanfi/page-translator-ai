AI Page Translator는 **Brave** 와 기타 Chromium 기반 브라우저를 위한 확장 프로그램입니다. 제공자는 직접 준비합니다. 무료 Google Gemini 키, OpenAI 호환 엔드포인트(OpenRouter, Groq, NVIDIA, OpenAI…), 또는 **Ollama** 를 통한 완전한 로컬 모델입니다. 확장 프로그램은 읽고 있는 페이지를 그 자리에서 번역하고 레이아웃, 링크, 서식을 유지합니다.

어떤 텍스트도 번역 서비스를 거치지 않습니다. API 키는 브라우저를 벗어나지 않고, 분석 도구도 없으며, Ollama를 쓰면 텍스트가 컴퓨터 밖으로 나가지도 않습니다.

> **상태:** 버전 1.3.1 · 자동 테스트 95개 · 12개 항목 검증 · 텔레메트리 없음, 원격 코드 없음.

## 왜 또 다른 번역기인가?

대부분의 페이지 번역기는 한 번에 문장 하나만 보냅니다. 그래서 결과가 페이지가 아니라 문장 더미처럼 읽힙니다. 문맥이 사라지고, 용어가 흔들리고, 링크가 문장을 반으로 가르며, 대상 언어가 원문의 어순을 물려받습니다.

이 확장 프로그램은 텍스트 노드가 아니라 **블록**을 번역합니다:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

블록은 하나의 단위로 전송되고, 인라인 마크업은 번호가 붙은 토큰으로 바뀝니다:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

`<tN>…</tN>` 은 문장에 속한 인라인 내용(링크, 강조, span)을 표시하고, `<vN/>` 은 절대 번역하면 안 되는 내용(코드, 이미지, 폼 컨트롤, 위젯)을 표시합니다. 모델은 토큰을 옮길 수 있으므로 영어 어순에 묶이지 않고 링크 **주위에** 자연스러운 대상 언어 문장을 만듭니다.

돌아온 답은 페이지를 건드리기 전에 검증됩니다. 모든 토큰이 존재하고 짝이 맞고 유일해야 합니다. 링크를 잃은 번역은 거부되고, 더 엄격한 지시로 한 번 재시도되며, 그래도 안 되면 그대로 둡니다. 원래 요소 노드를 재사용하므로 `href`, 이벤트 리스너, 중첩 마크업이 그대로 살아남습니다. "원문 보기"는 원래 노드를 정확히 복원합니다.

## 기능

- **페이지 전체를 그 자리에서 번역** — 제목, 문단, 목록, 표, 캡션, 버튼.
- **링크와 인라인 서식 유지** — 토큰 검증; 사라진 링크가 조용히 적용되는 일은 없습니다.
- **자연스러운 또는 직역 스타일** — *자연스럽게*(기본)는 원어민 작가처럼 다시 쓰고, *직역*은 기술 페이지에서 원문에 가깝게 유지합니다.
- **언어별 스타일 가이드** — 페르시아어, 아랍어, 우르두어, 히브리어에 전용 지침, 나머지 18개 언어에 일반 지침.
- **결정적 타이포그래피 교정** — 페르시아어 `ی`/`ک`, `می`/`ها`/`تر` 의 제로 폭 공백, `، ؛ ؟` 는 모델이 틀려도 교정됩니다.
- **선택적 품질 점검** — 각 세그먼트를 {원문, 번역} 쌍으로 읽어 표현뿐 아니라 의미도 고칩니다.
- **용어집** — 모델이 지켜야 하는 "용어 → 번역" 쌍.
- **보호되는 콘텐츠** — `<pre>`, `<code>`, URL, 이메일, `translate="no"`, `contenteditable`, SVG, 폼 컨트롤, 확장 프로그램 자체 UI는 절대 전송되지 않습니다.
- **속성 레이블** — `alt`, `title`, `placeholder`, `aria-label` 은 별도 채널에서 문단이 아닌 레이블 어조로 번역됩니다.
- **동적 페이지** — 무한 스크롤이나 SPA에서 추가된 콘텐츠는 나타나는 즉시 번역되며 옵저버 루프가 생기지 않습니다.
- **오른쪽에서 왼쪽 제대로** — 번역된 블록마다 `dir`, `<html>` 에 `lang`, 페이지 전체를 뒤집지 않으며 모두 복원됩니다.
- **사이트별 기억** — 도메인별 대상 언어를 기억하고 로드 시 자동 번역할 수 있습니다.
- **API가 있는 무엇이든** — Gemini, Ollama, OpenAI 호환 엔드포인트를 service worker에서 호출하므로 CORS 문제가 없습니다.
- **메모리 캐시, 재시도, 분할** — 같은 텍스트는 한 번만 전송하고, 실패한 블록은 페이지를 실패시키지 않고 분할하며, 429/5xx는 대기 시간을 늘려 재시도합니다.
- **빌드 단계 없음** — 평범한 클래식 스크립트를 그대로 로드합니다.

## 설치

1. 이 저장소를 내려받고(**Code → Download ZIP** 또는 `git clone`) 폴더를 보관합니다.
2. `brave://extensions` (또는 `chrome://extensions`)를 엽니다.
3. **개발자 모드**를 켭니다.
4. **Load unpacked** 를 누르고 이 폴더(`manifest.json` 이 있는 폴더)를 선택합니다.
5. 팝업을 한 번의 클릭으로 쓰려면 확장 프로그램을 고정합니다.

빌드, 설치, 번들 단계가 없습니다. 확장 프로그램은 `manifest.json` 에 나열된 파일만 읽습니다. `tests/`, `scripts/`, `bench/`, `docs/`, `.github/` 는 개발 전용이며 절대 로드되지 않습니다.

최신 Chromium 기반 브라우저가 필요합니다. 닫힌 shadow root는 브라우저가 API를 제공할 때(Chromium 119+) 번역됩니다. 나머지는 이전 버전에서도 작동합니다.

## 다른 사람과 공유하기

`npm run release` 는 패키지를 만들고 `release/` 에 파일을 출력합니다(git에서 무시됨).

| 파일 | 무엇인지 | 설치 방법 |
|---|---|---|
| `page-translator-ai-<version>.zip` | 확장 프로그램 전체, 약 95KB, 내부에 `INSTALL.txt` | 압축을 풀고 **Load unpacked**; 스토어가 받는 파일도 같습니다 |
| `page-translator-ai-<version>.crx` | 서명된 패키지 | 스토어 밖 설치가 허용되는 `brave://extensions` 로 끌어다 놓기 |
| `page-translator-ai-signing-key.pem` | 서명 키 | 절대 공유하지 마세요. `npm run release` 가 재사용하므로 업데이트해도 확장 프로그램 ID가 같습니다 |

즉 건네는 것은 파일 하나이고, 그 안에 설치 단계가 들어 있습니다.

**정직한 한계:** 브라우저 확장 프로그램은 클라이언트 측 코드입니다. 설치한 사람은 그 파일을 읽을 수 있습니다. `.crx` 는 서명된 zip이고, 압축을 푼 확장 프로그램은 평범한 폴더입니다. 어떤 패키징이나 난독화도 이를 바꾸지 못합니다. 축소는 읽는 속도만 늦추고 스토어 정책은 난독화를 금지합니다. 소스를 정말 비밀로 유지해야 한다면 프롬프트와 제공자 호출을 직접 관리하는 서버로 옮기는 것뿐이며, 이는 "내 키로, 백엔드 없이" 설계를 포기하는 일입니다.

저장소를 주지 않고 배포하려면 zip을 Chrome 웹 스토어에 **비공개 또는 비공개 목록** 항목으로 게시하세요. 비기술 사용자에게 원클릭 설치가 가능한 유일한 방법입니다.

확장 프로그램 팝업 → **Options & settings**, 또는 `brave://extensions` → 세부정보 → 확장 프로그램 옵션.

| 제공자 | 엔드포인트 | 키 | 비고 |

그다음:

1. **기본 대상 언어**를 고릅니다.
2. **번역 스타일**을 고릅니다: *Natural*(권장) 또는 *Literal*.
3. 필요하면 **Quality mode** 를 켜고 **용어집**을 한 줄에 하나씩 추가합니다(`용어 → 번역`; `->`, `=>`, `=`, TAB도 됨).
4. **원문 언어**를 *Auto-detect* 로 두거나 직접 고릅니다.
5. **Test connection** 을 누르고 **Save settings** 를 누릅니다.

제공자 참고 사항:

- **Gemini의 사고 설정은 모델 세대별로 선택됩니다.** 2.5 Flash와 Flash-Lite는 사고 없이, 2.5 Pro는 최소 예산(128), 3.x/4.x는 낮은 수준으로 실행됩니다. 모델이 설정을 거부하면 해당 설정 없이 한 번 재시도합니다.
- **Ollama** 는 8192 토큰 컨텍스트 창으로 호출합니다. 더 작은 컨텍스트로 학습된 모델은 긴 페이지를 여전히 자르므로 페이지를 작은 단위로 나눕니다.
- **무료 한도**는 속도를 제한합니다. 확장 프로그램은 기다렸다가 재시도하며 텍스트를 조용히 버리지 않습니다.

## 사용법

- 아이콘 클릭 → 언어 선택 → **Translate this page**.
- **Show original / Show translation** 언제든 전환; 복원은 손실이 없습니다.
- 번역된 문단 위에 마우스를 올리면 원문을 볼 수 있습니다.
- 오른쪽 클릭 → **Translate this page** 또는 **Translate selection**.
- 키보드: `Ctrl+Shift+Y`(macOS는 `Cmd+Shift+Y`)로 번역을 켜고 끕니다. 브라우저의 확장 프로그램 단축키 페이지에서 바꿀 수 있습니다.
- **Auto-translate** 가 켜져 있고 사이트 설정이 저장되어 있으면 해당 페이지는 로드 시 자동 번역됩니다.
- 설정은 다음 번역부터 열린 탭에 적용됩니다. 새로 고칠 필요가 없습니다.

## 작동 방식

```
페이지 DOM
  └─ content script: 블록 단위 수집, 인라인 마크업을 <tN>/<vN/> 토큰으로 직렬화
       └─ 분할기: 요청당 24개 단위 / 2400자
            └─ service worker: 제공자에게 요청 (확장 프로그램 오리진, CORS 없음)
                 └─ 제공자: JSON 입력, JSON 출력, ID 유지
                      └─ 검증: 토큰 완전·균형·유일, ID 일치
                           └─ DOM: 원래 요소 노드 재사용, 텍스트만 기록
                                └─ MutationObserver: 나중에 추가된 콘텐츠 번역
```

정말로 중요한 설계 결정:

- **제공자 트래픽은 페이지 컨텍스트를 벗어나지 않습니다.** content script가 `AIPT_FETCH` 메시지를 보내고 service worker가 요청을 수행하므로 CORS가 엄격한 엔드포인트도 그대로 작동합니다. service worker는 `sender.id` 도 확인하므로 이 확장 프로그램만 프록시로 쓸 수 있습니다.
- **프롬프트는 계약이지 소원이 아닙니다.** ID가 들어가고 ID가 나옵니다. 세그먼트당 한 항목, 태그 불가침, 숫자·URL·코드·플레이스홀더는 그대로, 설명 추가 없음. 응답을 ID로 읽으므로 순서가 바뀌거나 일부 깨진 배열은 번역을 밀어내는 대신 안전하게 실패합니다.
- **언어마다 스타일 가이드가 있습니다.** 예를 들어 페르시아어 가이드는 페르시아어 어순과 동사를 요구하고(`بررسی کنید`, `بررسی را انجام دهید` 아님), 일반 문장으로 충분한 곳에서 `می‌باشد`/`بایستی`/`گردید` 를 금지하며, 라틴 문자는 실제 외래어만 남기고 문장 부호와 제로 폭 공백을 고칩니다. few-shot 예시는 목표를 설명하는 대신 보여 줍니다.
- **방향은 지역적입니다.** 페르시아어, 아랍어, 히브리어, 우르두어 블록은 `dir="rtl"` 을 받고 `<html>` 은 대상 언어를 받으며 페이지 나머지는 배치를 유지합니다. 전체 반전은 가운데 정렬 레이아웃과 코드 블록을 깨뜨렸습니다. 둘 다 원문과 함께 복원됩니다.
- **실패는 보이고 범위가 제한됩니다.** 해석할 수 없는 블록은 분할되고, 그래도 실패하는 단위는 원문으로 남아 상단 배너에 보고됩니다. 번역 중 취소는 깔끔하게 멈추고 반쯤 쓰인 DOM을 남기지 않습니다.

자세한 내용: [`docs/translation-quality-design.md`](../translation-quality-design.md).

## 개인정보와 권한

| 권한 | 필요한 이유 |
|---|---|
| `storage` | 설정, API 키, 용어집, 사이트별 환경설정을 `chrome.storage.local` 에 저장합니다. |
| `contextMenus` | 오른쪽 클릭 "이 페이지 / 선택 영역 번역". |
| `tabs` | 활성 탭에 메시지를 보내고 옵션을 엽니다. |
| `activeTab` | 직접 번역하는 페이지에서 동작합니다. |
| `<all_urls>` | 방문한 페이지에 content script를 주입하고 service worker가 설정한 엔드포인트를 호출하도록 허용합니다. |

- API 키는 이 브라우저의 로컬 저장소에만 저장되고 선택한 제공자에게만 전송됩니다.
- 분석, 텔레메트리, 원격 코드, 개발자 서버 호출, 계정이 없습니다.
- 모든 텍스트는 `textContent` / `createTextNode` 로 씁니다. 확장 프로그램 어디에도 `innerHTML`, `eval`, `new Function` 이 없습니다. 모델 출력은 텍스트로만 페이지에 도달하며 속성은 고정 허용 목록으로 제한됩니다. `href`, `src`, 이벤트 핸들러는 모델 출력으로 절대 쓰이지 않습니다.
- 사이트별 환경설정은 service worker의 단일 직렬화 기록기가 쓰므로 두 탭이 서로를 덮어쓰지 않습니다.
- 자동 언어 감지는 같은 제공자에게 최대 600자 샘플을 보냅니다. 원문 언어를 직접 고르면 이 요청 자체가 사라집니다.

보안 정책과 취약점 신고: [`SECURITY.md`](../../SECURITY.md).

## 알려진 제한

- **토큰 검증은 의도적으로 엄격합니다.** `<tN>` 을 계속 망가뜨리는 모델은 링크를 잃는 대신 해당 문단을 원문으로 남기고 그 사실을 알립니다. 구조화된 출력을 따르는 모델을 쓰세요. *Test connection* 은 토큰이 있는 문장을 시험합니다.
- **품질은 모델에 달려 있습니다.** 작은 로컬 모델은 쓸 만하지만 Gemini나 GPT급 모델보다 유창하지 않습니다. 스타일 계층은 도움이 되지만 지식을 더하지는 않습니다.
- **닫힌 shadow root와 cross-origin iframe** 은 확장 프로그램의 범위 밖입니다(브라우저 보안). 열린 shadow root와 동일 출처 프레임은 처리됩니다.
- **느슨한 텍스트가 섞인 컨테이너** (`<div>텍스트<p>…</p></div>`)는 그 텍스트에 대해 노드 단위 번역으로 돌아갑니다. 잘 구성된 페이지는 이 경우에 이르지 않습니다.
- **캐시는 메모리에 있습니다**(탭 세션 단위). 페이지를 새로 고치면 텍스트를 다시 요청합니다.
- **PDF는 번역되지 않습니다.** 내장 PDF 뷰어는 확장 프로그램이 스크립트로 제어할 수 없습니다.
- **무료 한도는 바뀝니다.** 속도 제한과 모델 이름은 제공자가 정하지, 이 확장 프로그램이 정하지 않습니다.

## 프로젝트 상태와 테스트

버전 1.3.1. 자동 테스트는 DOM 계층, 프롬프트와 파싱, 제공자 요청 형태, 엔진 동작, 옵션 UI를 다루며 **95개**입니다. `npm run verify` 는 12개 항목 검증을 더합니다: 구문, 테스트 스위트, HTML 싱크 금지, 키 유출 검사, 클래식 content script, 버전 일치, CHANGELOG 기록, 패키징.

```bash
npm install       # 개발 전용: DOM 테스트용 jsdom
npm test          # 테스트 95개
npm run bench     # 분할 벤치마크, API 키 불필요
npm run verify    # 구문 + 테스트 + 정책 검사 + 패키징 검사
npm run package   # 배포 가능한 파일만 dist/ 로 복사
npm run release   # dist 와 배포용 release/*.zip, *.crx, *.pem 생성
```

벤치마크는 번역 품질이 아니라 분할을 측정합니다. 예제 페이지 네 개에서 독립적인 텍스트 노드 수집기는 **108개 조각**을, 블록 수집기는 **63개 단위**를 만듭니다(전체 1.7배 적음, 뉴스 기사에서 **2.5배**). 25자 미만 조각은 **81개에서 34개**로 줄어듭니다. 번역 품질 자체는 연결한 모델에 달려 있습니다. 자동 테스트가 닿지 못하는 브라우저 수준 동작(RTL 렌더링, 툴팁, 실제 SPA 트래픽, 제공자 오류)은 [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) 의 수동 점검 목록에 있습니다.

CI는 push와 pull request마다 Node 20과 22에서 `npm run verify` 와 `npm run bench` 를 실행합니다([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).

## 기여하기

이슈와 pull request를 환영합니다. 변경을 보내기 전에 `npm run verify` 를 실행하세요. 확장 프로그램은 빌드 없이 유지하고, 제공자 트래픽은 service worker에 두고, `innerHTML` 을 절대 도입하지 마세요. 프롬프트를 바꾸면 테스트를 추가하거나 갱신하세요. 프롬프트, 파서, 정규화기는 함께 테스트합니다. 하나의 묶음으로만 작동하기 때문입니다.

전체 규칙, `docs/i18n/` 번역 정책, 커밋 관례는 [`CONTRIBUTING.md`](../../CONTRIBUTING.md) 에 있습니다.
