# AI Page Translator — ترجم صفحات الويب بذكاء اصطناعي خاص بك

**ترجم أي صفحة ويب إلى لغتك باستخدام مزوّد الذكاء الاصطناعي الذي تختاره — بلا خادم وسيط، بلا حساب، بلا تتبّع وبلا فاتورة لكل كلمة.**

`Manifest V3` · `بلا خطوة بناء` · `JavaScript خالص` · `الإصدار 1.3.1` · `22 لغة`

هذا الملف هو الترجمة العربية للـ[ـدليل الإنجليزي المرجعي](README.md). عند أي اختلاف، يكون النص الإنجليزي هو المعتمد.

AI Page Translator إضافة لمتصفح **Brave** وغيره من المتصفحات المبنية على Chromium. أنت من يختار المزوّد: مفتاح Google Gemini مجاني، أو أي واجهة متوافقة مع OpenAI (OpenRouter، Groq، NVIDIA، OpenAI…)، أو نموذج محلي بالكامل عبر **Ollama**. تترجم الإضافة الصفحة التي تقرأها في مكانها، مع الحفاظ على تخطيطها وروابطها وتنسيقها.

لا يمرّ أي نص عبر خدمة ترجمة وسيطة. مفتاح API لا يغادر متصفحك، ولا توجد أي أدوات تحليل، ومع Ollama لا يخرج النص من جهازك إطلاقًا.

> **الحالة:** الإصدار 1.3.1 · 95 اختبارًا آليًا · تحقّق من 12 نقطة · بلا قياس عن بُعد وبلا شيفرة عن بُعد.

## لماذا مترجم آخر؟

معظم مترجمات الصفحات ترسل جملة واحدة في كل مرة. ولهذا تبدو النتيجة كومة جمل لا صفحة: يضيع السياق، وتتقلّب المصطلحات، وتقطع الروابط الجمل نصفين، وترث اللغة الهدف ترتيب كلمات اللغة المصدر.

تترجم هذه الإضافة **كتلًا** لا عُقد نصية:

```
The <a>new privacy policy</a> takes effect <strong>immediately</strong>.
```

تُرسل الكتلة كوحدة واحدة، ويحلّ الترميز المضمّن محلّه رموز مرقّمة:

```
The <t1>new privacy policy</t1> takes effect <t2>immediately</t2>.
```

يشير `<tN>…</tN>` إلى المحتوى المضمّن الذي ينتمي إلى الجملة (رابط، توكيد، span)، ويشير `<vN/>` إلى محتوى لا يجوز ترجمته أبدًا (شيفرة، صور، عناصر نموذج، ودجات). ويُسمح للنموذج بتحريك الرموز، فيبني جملة طبيعية **حول** الرابط بدل أن يُقيَّد بالترتيب الإنجليزي.

وعند العودة، تُتحقَّق الاستجابة قبل لمس الصفحة: كل رمز يجب أن يكون حاضرًا ومتوازنًا وفريدًا. والترجمة التي تُسقط رابطًا تُرفض، وتُعاد مرة واحدة بتعليمات أشد، وإلا بقيت الكتلة كما هي. تُستخدم عُقد الصفحة الأصلية نفسها، فتبقى `href` ومستمعات الأحداث والوسوم المتداخلة سليمة. ويعيد خيار «إظهار الأصل» العُقد الأصلية تمامًا.

## المزايا

- **ترجمة الصفحة كاملة في مكانها** — العناوين والفقرات والقوائم والجداول والتعليقات والأزرار.
- **الحفاظ على الروابط والتنسيق المضمّن** — بتحقّق قائم على الرموز؛ والرابط المفقود لا يُطبَّق أبدًا بصمت.
- **نمطان: طبيعي أو حرفي** — «طبيعي» (الافتراضي) يعيد الصياغة كما يكتب كاتب أصلي، و«حرفي» يبقى قريبًا من نص المصدر للصفحات التقنية.
- **أدلة أسلوب لكل لغة** — إرشاد مخصص للفارسية والعربية والأردية والعبرية، ودليل عام للغات الثماني عشرة الأخرى.
- **تصحيح حتمي للإملاء والترقيم** — أحرف `ی`/`ک` الفارسية، والمسافات الصفرية في `می`/`ها`/`تر`، وعلامات `، ؛ ؟` تُصحَّح حتى إذا أخطأ النموذج.
- **مراجعة جودة اختيارية** — تقرأ كل مقطع كزوج {المصدر، الترجمة}، فتصحّح المعنى لا الصياغة وحدها.
- **قاموس مصطلحات** — أزواج «مصطلح ← ترجمة» يجب على النموذج الالتزام بها.
- **محتوى محمي** — `<pre>` و`<code>` والروابط والبريد الإلكتروني و`translate="no"` و`contenteditable` وSVG وعناصر النماذج وواجهة الإضافة نفسها لا تُرسل أبدًا.
- **وسوم السمات** — `alt` و`title` و`placeholder` و`aria-label` تُترجم في قناة منفصلة وبأسلوب الوسم لا بأسلوب الفقرة.
- **الصفحات الديناميكية** — المحتوى الجديد من التمرير اللانهائي أو تطبيقات الصفحة الواحدة يُترجم فور ظهوره، بلا حلقات مراقبة لا تنتهي.
- **دعم صحيح للاتجاه من اليمين إلى اليسار** — `dir` على كل كتلة مترجمة، و`lang` على `<html>`، بلا قلب للصفحة كلها؛ وكل شيء قابل للاستعادة.
- **ذاكرة لكل موقع** — تتذكر لغة الهدف لكل نطاق، ويمكنها الترجمة التلقائية عند التحميل.
- **أي خدمة لها API** — Gemini وOllama وأي واجهة متوافقة مع OpenAI، تُستدعى من service worker فلا مشكلات CORS.
- **ذاكرة مؤقتة وإعادة محاولة وتقسيم** — النص نفسه يُرسل مرة واحدة؛ والمقطع الفاشل يُقسَّم بدل أن تُفشل الصفحة؛ وأخطاء 429 و5xx تُعاد بمهلة متزايدة.
- **بلا خطوة بناء** — سكربتات كلاسيكية بسيطة، تُحمَّل كما هي.

## التثبيت

1. نزّل هذا المستودع (**Code → Download ZIP** أو `git clone`) واحتفظ بالمجلد.
2. افتح `brave://extensions` (أو `chrome://extensions`).
3. شغّل **Developer mode**.
4. اضغط **Load unpacked** واختر هذا المجلد (الذي يحتوي `manifest.json`).
5. ثبّت الإضافة إن أردت الوصول إليها بنقرة واحدة.

لا توجد أي خطوة بناء أو تثبيت أو تجميع. لا تقرأ الإضافة إلا الملفات المذكورة في `manifest.json`؛ أما `tests/` و`scripts/` و`bench/` و`docs/` و`.github/` فخاصة بالتطوير ولا تُحمَّل أبدًا.

تحتاج إلى متصفح حديث مبني على Chromium. تُترجم جذور الظل المغلقة (closed shadow roots) في المتصفحات التي تكشف واجهتها (Chromium 119 فأحدث)؛ ويعمل كل ما عدا ذلك في الإصدارات الأقدم.

## مشاركة الإضافة مع الآخرين

يبني الأمر `npm run release` الحزمة ويضع ملفاتها في المجلد `release/` (وهو مستبعد من git):

| الملف | ما هو | طريقة التثبيت |
|---|---|---|
| `page-translator-ai-<version>.zip` | الإضافة كاملة، نحو 95 كيلوبايت، مع `INSTALL.txt` بداخلها | يُفكّ الضغط ثم **Load unpacked**؛ وهو الملف نفسه الذي يقبله المتجر |
| `page-translator-ai-<version>.crx` | حزمة موقّعة | تُسحب إلى `brave://extensions` حيث يُسمح بالتثبيت خارج المتجر |
| `page-translator-ai-signing-key.pem` | مفتاح التوقيع | لا تشاركه أبدًا؛ يعيد `npm run release` استخدامه فيبقى معرّف الإضافة ثابتًا بين التحديثات |

أي أن ما تعطيه لغيرك ملف واحد، وداخله خطوات التثبيت.

**حدّ صريح:** إضافة المتصفح شيفرة على جهاز المستخدم. من يثبّتها يستطيع قراءة ملفاتها — فالـ`.crx` ملف zip موقّع، والإضافة غير المحزومة مجلد عادي. لا يغيّر التغليف أو التعمية هذه الحقيقة؛ فالتعمية تبطئ القراءة فقط، وسياسة المتاجر تمنعها. وإذا كان يجب أن تبقى الشيفرة سرية فعلًا، فالخيار الوحيد المعقول هو نقل الطلبات والاتصال بالمزوّد إلى خادم تديره أنت، وهذا يعني التخلي عن تصميم «مفتاحك أنت، بلا خادم».

لتوزيع الإضافة دون تسليم المستودع، انشر ملف zip كعنصر **خاص أو غير مُدرج** في Chrome Web Store؛ فهذا هو السبيل الوحيد للتثبيت بنقرة واحدة لمستخدم غير تقني.

## إعداد مزوّد الخدمة

نافذة الإضافة ← **Options & settings**، أو `brave://extensions` ← Details ← Extension options.

| المزوّد | نقطة النهاية | المفتاح | ملاحظات |
|---|---|---|---|
| **Ollama** (محلي) | `http://localhost:11434` | لا يحتاج | مجاني وخاص تمامًا. ثبّته من [ollama.com](https://ollama.com) ثم نفّذ `ollama run llama3`. إذا أعاد 403، أعد تشغيله مع `OLLAMA_ORIGINS=chrome-extension://*`. |
| **Google Gemini** | `generativelanguage.googleapis.com` | مفتاح مجاني من [AI Studio](https://aistudio.google.com/app/apikey) | استخدم معرّف نموذج حديثًا مثل `gemini-2.5-flash`. حصص المجانية تتغير؛ راجع قائمة نماذج Google. |
| **متوافق مع OpenAI** | نقطة النهاية الخاصة بك، مثل `https://openrouter.ai/api/v1` أو `https://api.groq.com/openai/v1` أو `https://integrate.api.nvidia.com/v1` | مفتاح المزوّد | أي خدمة تدعم `/chat/completions`. النماذج المقترحة في الواجهة أمثلة فقط؛ استخدم المعرّف الدقيق من كتالوج المزوّد. |

ثم:

1. اختر **لغة الهدف الافتراضية**.
2. اختر **نمط الترجمة**: *Natural* (موصى به) أو *Literal*.
3. يمكنك تشغيل **Quality mode** وإضافة مصطلحات إلى **القاموس**، سطرًا لكل مصطلح (`مصطلح ← ترجمة`؛ ويعمل أيضًا `->` و`=>` و`=` وTAB).
4. اترك **لغة المصدر** على *Auto-detect* أو اخترها يدويًا.
5. اضغط **Test connection** ثم **Save settings**.

ملاحظات عن المزوّدين:

- **يُختار إعداد التفكير في Gemini حسب جيل النموذج.** يعمل 2.5 Flash وFlash-Lite بلا تفكير، ويستخدم 2.5 Pro حدّه الأدنى (128)، وتستخدم 3.x/4.x مستوى تفكير منخفضًا. وإذا رفض النموذج هذا الإعداد، تُعاد الطلب مرة واحدة بدونه.
- **Ollama** يُستدعى بنافذة سياق من 8192 رمزًا؛ والنموذج المدرَّب على سياق أقل سيقتطع الصفحات الطويلة، ولذلك تُقسَّم الصفحة إلى وحدات صغيرة.
- **الحصص المجانية** محدودة. تنتظر الإضافة قليلًا ثم تعيد المحاولة؛ ولا تحذف نصًا بصمت.

## الاستخدام

- اضغط الأيقونة ← اختر لغة ← **Translate this page**.
- **Show original / Show translation** في أي وقت؛ والاستعادة بلا فقدان.
- مرّر المؤشر فوق فقرة مترجمة لترى النص الأصلي.
- انقر بالزر الأيمن ← **Translate this page** أو **Translate selection**.
- لوحة المفاتيح: `Ctrl+Shift+Y` (وفي macOS: `Cmd+Shift+Y`) تبدّل الترجمة؛ ويمكن تغييره من صفحة اختصارات المتصفح.
- مع تشغيل **Auto-translate** ووجود تفضيل محفوظ للموقع، تُترجم الصفحات المطابقة عند التحميل.
- تُطبَّق الإعدادات على التبويبات المفتوحة عند الترجمة التالية؛ بلا حاجة إلى إعادة تحميل.

## كيف تعمل

```
DOM الصفحة
  └─ content script: جمع وحدات الكتل، وتحويل الترميز المضمّن إلى رموز <tN>/<vN/>
       └─ المقسّم: 24 وحدة أو 2400 حرف لكل طلب
            └─ service worker: إرسال الطلب إلى مزوّدك (أصل الإضافة، بلا CORS)
                 └─ المزوّد: JSON يدخل وJSON يخرج والمعرّفات محفوظة
                      └─ التحقّق: اكتمال الرموز وتوازنها وتفرّدها ومطابقة المعرّفات
                           └─ DOM: إعادة استخدام العُقد الأصلية وكتابة النص فقط
                                └─ MutationObserver: ترجمة المحتوى المضاف لاحقًا
```

قرارات تصنع الفرق فعلًا:

- **حركة المزوّد لا تنطلق من سياق الصفحة أبدًا.** يرسل content script رسالة `AIPT_FETCH`، وينفّذ service worker الطلب، فتعمل نقاط النهاية الصارمة في CORS كما هي. ويتحقق service worker أيضًا من `sender.id`، فلا تستطيع إلا هذه الإضافة استخدامه كوسيط.
- **الطلب عقد لا أمنية.** معرّفات تدخل ومعرّفات تخرج؛ مدخل لكل مقطع؛ الوسوم لا تُمسّ؛ الأرقام والروابط والشيفرة والعناصر النائبة كما هي؛ بلا شروح مضافة. وتُقرأ الاستجابات بالمعرّف، فالمصفوفة المعاد ترتيبها أو المشوّهة جزئيًا تفشل بأمان بدل أن تُزيح الترجمات.
- **لكل لغة دليل أسلوبها.** دليل الفارسية مثلًا يطلب ترتيب الكلمات والأفعال الفارسية (`بررسی کنید` لا `بررسی را انجام دهید`)، ويمنع `می‌باشد`/`بایستی`/`گردید` حيث تكفي جملة عادية، ويُبقي في الحروف اللاتينية إلا المستعار الحقيقي، ويصحح الترقيم والمسافات الصفرية. وأمثلة few-shot تُظهر للنموذج الهدف بدل وصفه.
- **الاتجاه محلي.** تتلقى كتل الفارسية والعربية والعبرية والأردية `dir="rtl"`، ويتلقى `<html>` لغة الهدف، ويحتفظ بقية الصفحة بهندسته — فقلب الصفحة كلها كان يفسد التخطيطات الموسّطة وكتل الشيفرة. ويُستعاد الاتجاه مع النص الأصلي.
- **الأخطاء ظاهرة ومحسورة.** المقطع الذي يتعذّر تحليله يُقسَّم؛ والوحدة التي تفشل مرة أخرى تبقى بلغتها الأصلية ويُبلَّغ عنها في الشريط. والإلغاء أثناء الترجمة يتوقف بنظافة ولا يترك DOM نصف مكتوب.

تفاصيل أكثر: [`docs/translation-quality-design.md`](../translation-quality-design.md).

## الخصوصية والأذونات

| الإذن | لماذا نحتاجه |
|---|---|
| `storage` | حفظ الإعدادات ومفتاح API والقواميس وتفضيلات كل موقع في `chrome.storage.local`. |
| `contextMenus` | خيار النقر بالزر الأيمن «ترجمة هذه الصفحة / التحديد». |
| `tabs` | إرسال الرسائل إلى التبويب النشط وفتح صفحة الخيارات. |
| `activeTab` | العمل على الصفحة التي تترجمها بنفسك. |
| `<all_urls>` | حقن content script في الصفحات التي تزورها، والسماح لـ service worker بالاتصال بنقطة نهاية المزوّد. |

- يُخزَّن مفتاح API في التخزين المحلي لهذا المتصفح فقط، ولا يُرسل إلا إلى المزوّد الذي اخترته.
- بلا أدوات تحليل، بلا قياس عن بُعد، بلا شيفرة عن بُعد، بلا اتصال بخادم المطوّر وبلا حساب.
- يُكتب كل النص بـ`textContent` و`createTextNode`؛ ولا يوجد في الإضافة أي `innerHTML` أو `eval` أو `new Function`. ولا يصل خرج النموذج إلى الصفحة إلا كنص، والسمات محدودة بقائمة مسموحة ثابتة؛ فلا تُكتب `href` ولا `src` ولا مستمعات الأحداث من خرج النموذج.
- تُكتب تفضيلات كل موقع عبر كاتب واحد متسلسل في service worker، فلا يستطيع تبويبان محو كتابة أحدهما الآخر.
- يرسل الكشف التلقائي للغة عيّنة لا تتجاوز 600 حرف إلى المزوّد نفسه؛ وإذا اخترت لغة المصدر يدويًا يُلغى هذا الطلب كليًا.

سياسة الأمان وطريقة الإبلاغ عن ثغرة: [`SECURITY.md`](../../SECURITY.md).

## قيود معروفة

- **التحقّق من الرموز صارم بحكم التصميم.** النموذج الذي يشوّه `<tN>` باستمرار سيُبقي تلك الفقرات بلغتها الأصلية (وسيعلن ذلك) بدل أن يُسقط رابطًا. استخدم نموذجًا يحترم الخرج المنظّم؛ و*Test connection* يختبر جملة موسومة.
- **الجودة تعتمد على النموذج.** النماذج المحلية الصغيرة قابلة للاستخدام لكنها أقل طلاقة من Gemini أو نماذج فئة GPT؛ وطبقة الأسلوب تساعد ولا تضيف معرفة.
- **جذور الظل المغلقة وإطارات cross-origin** خارج متناول الإضافة (أمان المتصفح). أما جذور الظل المفتوحة والإطارات ذات الأصل نفسه فمدعومة.
- **الحاويات المختلطة بنص حر** (`<div>نص<p>…</p></div>`) تعود إلى الترجمة عقدة بعقدة لذلك النص؛ والصفحات السليمة لا تصل إلى هذه الحالة أبدًا.
- **الذاكرة المؤقتة في RAM** (خلال جلسة التبويب). وإعادة تحميل الصفحة تطلب نصها من جديد.
- **لا تُترجم ملفات PDF**؛ فعرض PDF المدمج غير قابل للبرمجة من الإضافات.
- **الحصص المجانية تتغير.** حدود المعدل وأسماء النماذج يحددها المزوّد لا هذه الإضافة.

## حالة المشروع والاختبارات

الإصدار 1.3.1. تغطي المجموعة الآلية طبقة DOM، والطلب والتحليل، وشكل طلبات المزوّدين، وسلوك المحرك، وواجهة الخيارات — **95 اختبارًا** — ويضيف `npm run verify` تحقّقًا من 12 نقطة: فحص الصياغة، ومجموعة الاختبارات، ومنع مصارف HTML، وفحص تسرّب المفتاح، وسكربتات المحتوى الكلاسيكية، وتوافق الإصدارات، وتغطية CHANGELOG، والتغليف.

```bash
npm install       # للتطوير فقط: jsdom لاختبارات DOM
npm test          # 95 اختبارًا
npm run bench     # قياس التقسيم، بلا حاجة إلى مفتاح API
npm run verify    # الصياغة + الاختبارات + فحوص السياسة + التغليف
npm run package   # نسخ الملفات القابلة للتوزيع فقط إلى dist/
npm run release   # dist مع release/*.zip و*.crx و*.pem للتوزيع
```

يقيس هذا القياس التقسيم لا جودة الترجمة: على الصفحات الأربع النموذجية ينتج جامع مستقل يعمل على عُقد النص **108 قطع**، بينما ينتج جامع الكتل **63 وحدة** (أقل بـ1.7 مرة إجمالًا، و**2.5 مرة** في المقال الإخباري)، وتنخفض القطع الأقصر من 25 حرفًا من **81 إلى 34**. أما جودة الترجمة نفسها فتعتمد على النموذج الذي توصله؛ وتغطي القائمة اليدوية في [`TEST_CHECKLIST.md`](../../TEST_CHECKLIST.md) ما لا تصل إليه الاختبارات الآلية (عرض RTL، والتلميحات، وحركة SPA الحقيقية، وأخطاء المزوّد).

تشغّل CI الأمرين `npm run verify` و`npm run bench` على Node 20 و22 عند كل push وpull request ([`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)).

## المساهمة

نرحّب بالمشكلات وطلبات السحب. قبل إرسال تغيير، شغّل `npm run verify`؛ وأبقِ الإضافة بلا خطوة بناء، وأبقِ حركة المزوّد في service worker، ولا تُدخل `innerHTML` أبدًا. وإذا غيّرت الطلب، أضف اختبارًا أو حدّثه؛ فالطلب والمحلّل والمطبِّع تُختبر معًا لأنها لا تعمل إلا كمنظومة واحدة.

اقرأ [`CONTRIBUTING.md`](../../CONTRIBUTING.md) للقواعد الكاملة، وسياسة ترجمة `docs/i18n/`، واصطلاحات رسائل commit.
